## 5. 环境与装置的硬事实（不重新踩）

**构建/取证**
- 构建命令**禁接管道**（`| tail` 吞退出码）；判成败看 `echo $?`。
- **worktree 一律不设 `FETCHCONTENT_BASE_DIR`**；干净复验另建目录（`/tmp` 会被系统清，**禁用**）。
- 键盘/鼠标注入**必须 HID 层**（`ti2input`，源码 `docs/qa/T-D40-*/tools/td40input.m`，
  构建需 `-framework AppKit`）；**禁止 `osascript`**；合成的"绝对坐标移动"delta 恒 0，
  必须写 `kCGMouseEventDeltaX/Y` 增量。
- **窗口号按 PID 反查 + 按尺寸过滤**（MV 会多开 3–5 个幽灵窗）；`ps|grep opencraft` 会命中 zsh 包装进程。
- **md5 ≠ 像素哈希**：截图 A/B 必须解码逐像素（`docs/qa/T-*/tools/pixel_diff.py`）。
- clang-format 用 **CLT 的 17**（`/Library/Developer/CommandLineTools/usr/bin/clang-format`），
  不是 brew 的 23；且按目录树读 `.clang-format`，拷到 /tmp 检查无效。
- **取消前台 Bash 会杀掉同组后台构建**（进程组）——用阻塞式 TaskOutput 或一次性 status 检查，
  不要用可取消的前台调用当轮询。

**美术线（已有大量资产，别重做）**
- 方块贴图：**60/63**（分母含 air 3 格，**60 才是上限**）；`assets/blocks/<id>_<slot>.png` 严格 16×16
  **不缩放**；**PNG 行 0 = 面的上沿**（解码要上下翻转）。

  必须落头关节包围盒内。

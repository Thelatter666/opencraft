# 06 · 路线图

里程碑制，每个里程碑内按 §05 的任务卡流转。判据：每个 M 结束时"可构建、可运行、验收清单通过"。

## M0 · 文档与脚手架（当前）
- [x] 调研笔记 4 份（机制/世界生成/引擎/合规）
- [x] 规格文档 00–06
- [ ] 仓库初始化：CMake 骨架、CI（三平台构建）、clang-format、空主程序能开窗口清屏
- 验收：`cmake --build` 三平台绿；`opencraft` 启动出 1280×720 窗口

## M1 · 走在一个世界里（核心循环立起来）
- 区块存储 + 调色板；单一噪声地形（含基本洞穴）；culled meshing + 纹理图集
- 第一人称控制器（走/跑/跳/潜行，`01-gameplay-spec.md` §2 全部数值 tick 级对齐）
- DDA 选取 + 挖掘/放置（含 10 阶段裂纹、挖掘时间公式）
- 简易 HUD（准星、快捷栏、生命条）、暂停菜单、保存/读档（区域文件+zstd）
- 验收：新档 5 分钟闭环——走到哪挖到哪建到哪，退游戏重进世界不丢；物理回放黄金测试绿

> **⚠ 本路线图已于 2026-09-16 修订**（用户裁决：结构优先）。修订理由与依据见 §「修订记录」。
> 原 M2 是一整块「生存规则全量」，中间无可验收里程碑；原 M3 的多人排在所有内容之后，
> 恰好撞上最贵的权威侧重构。现拆为 M2a/M2b/M2c 三个可独立验收的子阶段。

## M2a · 地基（结构优先，2026-09-16 新增）
- `main.cpp` 拆分：渲染 / 输入 / UI / 世界接线分离（现 1628 行，每张卡都动它 ⇒ 冲突源）
- 物品与库存无头库（ItemRegistry / ItemStack / 27+9+4+1 / 堆叠 64-16-1）
- 方块状态扩展：部分高度方块（碰撞高度 + 半高网格化）⇒ 解锁 step-assist 实机可达（T-D17 重定项）
- 验收：拆分后 243 测试全绿且行为零变化；物品库单测覆盖；半砖可放置/可站立

## M2b · 权威侧前置（**从原 M3 提前**，2026-09-16）
- 世界模拟与客户端分离（**进程内先分，不引网络**）：客户端不再直接改世界
- 命令/事件通道（挖/放/攻击走校验后的事件）
- 区块流式加载 + 卸载策略（债务 T-D4）
- 验收：进程内权威闭环，客户端预测与和解可测；出视野卸载且脏数据先落盘

> **提前的理由**：`engine/net` 当前为空（0 源文件），权威侧实际缺失。
> 内容卡越多，客户端里"直接改世界"的代码越多，权威侧重构越贵。**现在拆最便宜。**

## M2c · 生存规则（原 M2 内容）
- 库存/掉落物/合成 2×2 与 3×3/烧炼；工具 tiers 与采掘等级；饥饿-饱和-耗竭全模型
- 攻击冷却/暴击/击退；生命-护甲-伤害公式；经验与死亡掉落；昼夜+床等价物；难度与 gamerule
- 首批被动生物 4 种 + 敌对 3 种，刷怪规则（光照 0、环带、cap）
- 验收：空手→木→石→铁→钻石等价物进程走通；数值对账表全绿；手感清单 §3/§4 人工过

## M3 · 世界成型 + 多人（**变薄**）
- 六参数群系生成（首发 ~25 群系）、三类洞穴、矿石分布曲线、5 种结构、地表装饰跨区块
- 光照引擎完整版（双通道、删除重加、跨区块）→ 平滑光照+AO
- 多人 = **把 M2b 的进程内通道换成网络**（此时应很薄）：独立服务端进程、客户端预测与和解、
  区块异步发送、远程实体插值
- 验收：种子确定性测试绿；同种子矿物/群系分布曲线对账；2 客户端同服挖建同步且无明显回拉

## M4 · 生存内容扩容
- 附魔（基础集）、酿造、锻造；村庄交易等价物；生物扩到 15–25 种；天气/月相/区域难度
- 进度系统雏形（JSON 数据驱动）；统计；创造模式完整（飞行、无限物品、方块拾取）
- 验收：完整生存通关到"进阶维度入口前置"；性能预算达标（渲染视距 12 区块 ≥60fps @ i5）

## M5 · 维度与终局
- 下界等价物（1:8、封闭岩层、群系、结构、重生锚）；末地等价物（主岛+外岛+折跃）
- 两个 Boss 等价物（200/300HP 机制对齐）；终局装备 tier；进度树全量（~120 节点）
- 验收：新档全程通关（含 Boss）无阻塞；Boss 战数值对账

## M6 · 打磨与发布
- 红石等价物（逻辑电路系统）或宣布后置；音频全套（原创）；设置菜单/按键映射/无障碍
- 性能：贪心网格化、LOD 评估、加载时间优化；法律自查（04 文档红线逐项）；许可定稿（代码+资产双许可）
- 验收：0.1 公开版发布

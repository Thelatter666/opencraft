# 00 · 愿景与范围

## 愿景

OpenCraft 是一个开源的、用 C++ 实现的体素沙盒游戏，让玩家获得与 Minecraft Java Edition 高度一致的游玩体验——同样的移动手感、同样的挖掘与建造节奏、同样的生存进程——但底层是彻底原创的代码栈与资产库。

## 对齐原则

"对齐"只针对**公开可观察层**，按优先级排序：

1. **数值行为**：移动速度、跳跃弧线、重力、挖掘时间、伤害公式、饥饿速率等可直接测量的量，向 MC JE 对齐（数值来源：`research/01`、`research/02`）。目标是"拿到 MC 里练出的肌肉记忆在 OpenCraft 里同样成立"。
2. **交互手感**：挖掘进度+裂纹十阶段、6 tick 连挖延迟、攻击冷却与攻击条、击退与受击反馈、疾跑 FOV 拉伸、潜行防坠落。手感是数值+反馈的组合，逐项对齐。
3. **内容组织**：生存→下界→末地的进程线、附魔/药水/村民交易的位置、群系与结构的分布逻辑、昼夜/天气节律。名称与外观必须原创，功能位置对齐。
4. **不承诺对齐的**：红石全逻辑门的精确时序怪癖、Bug 兼容性（Buxbug 类行为）、多人协议、模组生态兼容。这些列为"后续视情况"。

## 原创性硬约束

- 代码：全部自研。可以读公开技术文章、wiki 上的**事实与数值**，不得参照反编译代码、MCP/Yarn 映射产物。
- 资产：纹理/模型/音效/字体/音乐全部自制或来自 CC0/明确许可来源；风格允许"16×16 像素风"这种**风格类别**，不允许接近具体原版纹理的构图与配色。
- 命名：游戏名、方块/物品/生物/群系名全部原创；宣传中不得使用 Minecraft 商标暗示关系（详见 `04-legal-compliance.md`）。

## 范围

### 第一版（M1–M4）范围内
- 单机（含本地内嵌服务端）生存+创造模式
- 无限世界：主世界地形/洞穴/矿石/地表、基础群系、树木、村庄等少量结构
- 完整生存循环：采集→合成→烧炼→附魔（基础）→装备 tiers
- 核心敌对/被动生物（约 15–25 种）、刷怪规则、昼夜与天气
- 床/重生点、经验、死亡掉落、难度机制

### 第二版（M5+）范围
- 下界与末地维度、Boss（原创等价物）、更多群系与结构
- 局域网/独立服务端多人、基础红石等价物（"逻辑电路系统"）
- 成就/进度树、统计

### 非目标（明确不做）
- 兼容 Minecraft 存档/协议/模组
- 移动端、主机版（桌面三平台 first：Windows/macOS/Linux）
- 复刻基岩版特性

## 成功标准

1. **手感盲测**：熟悉 MC 的玩家在无提示情况下，OpenCraft 的移动、挖掘、战斗节奏"感觉对"。
2. **数值对账**：规格文档中的关键数值（见 `01-gameplay-spec.md` 数值表）实现误差为 0（tick 级公式一致）。
3. **生存进程可走通**：新档空手→木器→石器→铁器→钻石等价物→进阶维度入口，全程无阻塞。
4. **合规自查通过**：`04-legal-compliance.md` 红线清单逐项通过。

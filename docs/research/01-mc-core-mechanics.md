# OpenCraft 调研笔记 01：Minecraft Java Edition 核心玩法机制与数值

> 调研目的：为 OpenCraft（原创代码/资产、玩法机制对齐 Minecraft Java Edition 的 C++ 体素沙盒）提供"玩家可感知机制"的精确数值与手感描述。
> 调研日期：2026-09-13。主要来源：Minecraft Wiki（minecraft.wiki，下文简称 MW 各页面）、Minecraft.net 官方新闻。
> 版本基准：截至 2026-09-13，Java Edition 最新正式版约为 **26.2**（2026 年起 Mojang 改用年份版本号：26.1 / 26.2 / 26.3；"Mounts of Mayhem"为 2025-12 的 1.21.x 最后阶段更新）。**26.3 "Wilderness Bound" 定于 2026-09-15 发布**，本笔记数值以 1.21.x→26.x 连续机制为准，个别"26.3 前后变化"处单独标注（如末影龙头部减伤 bug 在 JE 26.3 修复）。

## 1. 玩家物理（来源：MW "Player"、"Sprinting"、"Falling"/"Fall damage"、"Breaking"）

### 1.1 移动速度（地面）
| 状态 | 速度 | 备注 |
|---|---|---|
| 行走 | **4.317 m/s**（0.2159 格/tick） | 100% 基准 |
| 疾跑 | **5.612 m/s** | 行走的 130% |
| 潜行 | **1.295 m/s** | 行走的 30%；关键手感：潜行时不会从方块边缘掉落 |
| 疾跑跳（平均水平） | **7.127 m/s** | 单次疾跑跳最远 ~4 格（常态跳跃只有 ~2 格）；头顶 2 格高时可达 5 格 |
| 飞行（创造） | 10.79 m/s；疾跑飞行 21.58 m/s | |
| 终端速度（下落） | **77.71 m/s**（~3.9 格/tick） | |

- 速度公式（概念模型）：`v_terminal = a / (1 - r)`，即每 tick 加速度 a 与阻尼系数 r 决定；这是"手感"的底层：**每 tick 速度衰减（drag）+ 加速度**，OpenCraft 应在 tick 级模拟而非帧级。
- 疾跑规则：需饥饿 > 6；疾跑有 **0.6 秒左右启动判定**（双击 W 或按 Ctrl），疾跑中视野 FOV 会**放大**（**+15%**，即 70° → 80.5°，随速度平滑过渡；本行原估"+10% 左右"已被 T-D1 实测推翻，以 `docs/research/05-mc-movement-feel.md` §2 为准）——这是重要的"速度感"来源，OpenCraft 必须实现。
- 疾跑时对生物撞击产生**额外击退**（疾跑击退）。

### 1.2 跳跃与重力
- 跳跃高度：**1.2522 格**（JE，15w45a 起为 1.2522；旧值/基岩为 1.24919）。能跳上 1 格高、含半砖+地毯的组合但**跳不上 1.5 格**。
- 初始跳跃速度 **0.42 格/tick**，重力 **0.08 格/tick²**，每 tick 速度再乘 0.98 阻尼；水平空中控制力远弱于地面（空中加速度约为地面的一小部分）——这是 MC 跳跃手感的核心参数组。
- 跳跃消耗饥饿（见 §4）。

### 1.3 掉落伤害（来源：MW "Fall damage"）
- 公式：`伤害 = max(0, floor(下落距离 - 3))`，即**超过 3 格后每格 1 HP**（摔落 23.5 格以上才会真正致死，尽管 23 格理论即致命——因落地判定顺序）。
- 减免/重置：
  - 水（入水即重置）、蜘蛛网、细雪、梯子/藤蔓：完全重置下落距离；
  - 黏液块：无伤但弹跳（潜行落地不弹）；
  - 干草块/蜂蜜块：伤害降为 **20%**；床：按 50% 下落距离计算；甜浆果丛：无伤；
  - 岩浆：每 tick 下落距离减半（累计）。
- 附魔：摔落缓冲每级 EPF 3（IV 级=12 EPF）；保护/抗性（每级 20%）；跳跃提升每级 -1 HP。
- 虚空：Y < 世界底部（JE -64 以下）每 0.5 秒 **4 HP**，无视创造/旁观。

### 1.4 水中/岩浆中
- 水中移动速度大幅下降（约 2 m/s 量级；游泳潜行更慢）；疾速游泳（Sprint-swim）约 **2.2 m/s**，海豚恩典下 ~9.8 m/s。
- 水下挖掘：无"水下速掘（Aqua Affinity）"时挖掘速度 **÷5**；头不在水中则不罚。脚未着地同样 **÷5**；两者叠加=陆上 25 倍慢。
- 水中憋气：10 个气泡（300 tick，15 秒），每秒扣 1 气泡；归零后每秒 1 HP 窒息伤害。
- 岩浆中：移动更迟缓、持续着火（离火后仍燃烧 15 秒，每秒 1 HP）；下界耐火（Fire Resistance 药水）免疫。
- 物品实体在水中缓慢上浮；下界合金物品**在岩浆中不烧毁**并漂浮。

### 1.5 生命值
- 玩家 **20 HP**（10 颗心）；护甲值上限 20（属性上限 30）；盔甲韧性上限 20。
- 受击后 10 tick（0.5 秒）无敌帧；同一实体上 DPS 实际被无敌帧限制（"对单目标 DPS 有效上限约 2 次/0.5s"）。
- 受击产生**受伤红闪 + 相机受击抖动（hurt tilt）**，音效按材质分类——手感要点。

## 2. 护甲与伤害计算（来源：MW "Armor"）

### 2.1 护甲减伤公式（JE）
```
reduction = min(20, max(armor/5, armor - 4*damage/(min(toughness,20)+8))) / 25
最终伤害 = damage * (1 - reduction)
```
- 简记：低伤害时每点护甲约减 **4%**；上限 **80%**。
- 韧性作用点：`BreakingPoint = armorPoints × (toughness + 8) / 5`，超过此伤害韧性失效、退到最小减伤（armor/5×4%每点）。
- 钻石全套（20 甲、12 韧）对普通僵尸一击减伤约 77%，对高伤（猪灵蛮兵）只有约 67%——**护甲对大伤害非线性衰减**。

### 2.2 附魔保护（EPF）
- 所有适用附魔 EPF 求和，**上限 20**，减伤 = EPF/25（最高 80%）。
- 每级 EPF：保护 1（IV=4）、火焰/爆炸/弹射物保护 2（IV=8）、摔落缓冲 3（IV=12）。
- 附魔减伤作用于"穿透护甲后的剩余伤害"。

### 2.3 主要伤害类型豁免
- 摔落：护甲不减伤，仅摔落缓冲/保护/抗性有效。
- 窒息/虚空/凋零/饥饿（ starvation ）：绕过护甲与保护。
- 铁傀儡/守卫者等"魔法伤害"：绕过护甲，可被保护减免。

## 3. 饥饿系统（来源：MW "Hunger"）

- 玩家：饥饿 20 点（10 鸡腿）+ **饱和度**（隐藏值，上限=当前饥饿值）+ 耗竭度（exhaustion，累积 4.0 触发一次扣减：先扣饱和度，再扣饥饿）。
- 各行为耗竭值：
  | 行为 | 耗竭 |
  |---|---|
  | 破坏方块 | 0.005/块 |
  | 游泳 | 0.01/米 |
  | 跳跃 | 0.05/次 |
  | 疾跑 | 0.1/米 |
  | 疾跑跳 | 0.2/次 |
  | 攻击命中 | 0.1/次 |
  | 受到有护甲保护的伤害 | 0.1/次 |
  | 自然回血 | **6.0/每回 1 HP** |
- 自然回血：饥饿 ≥18 时**每 4 秒回 1 HP**（扣 6 耗竭）。
- 饱和度急救（Saturation boost，仅 JE）：饥饿=20 且饱和度>0 时**每 0.5 秒消耗 1.5 饱和度回 1 HP**——吃高饱和食物（金胡萝卜：8 饥饿/14.4 饱和）回血飞快的原因。
- 饥饿 =0：每 4 秒扣 1 HP；困难无下限，普通降到 1 HP，简单降到 10 HP。
- 饥饿 ≤6 禁止疾跑。
- 疾跑消耗量：饱和度耗尽后**每 40 米或每 7 秒掉 0.5 饥饿**。
- 常用食物（饥饿/饱和）：牛排/熟猪排 8/12.8、金胡萝卜 8/14.4、金苹果 4/9.6、面包/烤土豆 5/6.0、腐肉 4/0.8（附加饥饿 I 30 秒=3.0 耗竭）。进食耗时 1.6 秒（32 tick，干海带 0.8 秒）。

## 4. 经验值（来源：MW "Experience"）

- 升级所需 XP：
  - 0–15 级：`2×level + 7`
  - 16–30 级：`5×level - 38`
  - 31+ 级：`9×level - 158`
  - 总量参考：0→1 级 7 XP；0→16 级 352；**0→30 级 1395**（附魔台上限）；铁砧上限 39 级。
- XP 球：离散值 1/3/7/17/37/73/149/307/617/1237/2477，大值优先拆分；**5 分钟消失**；可被火/岩浆/爆炸销毁。
- 挖矿 XP：煤矿 0–2、红石 1–5、青金石/石英 2–5、钻石/绿宝石 **3–7**、下界金 0–1、刷怪笼 15–43；精准采集挖矿无 XP；烧炼 XP 按小数累计（圆石 0.1/个）。
- 生物 XP：普通敌对 5（幼年僵尸 12；烈焰人/守卫者 10；劫掠兽/猪灵蛮兵 20）；**必须由玩家（或驯服狼）在 5 秒内造成过伤害才掉 XP**。
- 玩家死亡掉落：每级 7 XP，上限 100。

## 5. 方块交互：挖掘（来源：MW "Breaking"、"Instant mining"）

### 5.1 挖掘时间公式（JE 精确版）
每 tick 对方块累积"破坏值"：
```
speedMultiplier = 工具等级倍率(若为正确工具类型) + 效率附魔加成
若正确工具: damage = speedMultiplier / hardness / 30
若不可收获: damage = 1 / hardness / 100（正确类型但等级不足时用等级倍率但除以 100？——准确规则：canHarvest=false 时 damage/=100）
tick 数 = ceil(1 / damage)；时间(秒) = tick数/20
基础秒数 = hardness × 1.5（可收获）或 hardness × 5（不可收获）
```
- 工具等级倍率：徒手 1、**木 2、石 4、铜 5、铁 6、钻石 8、下界合金 9、金 12**；剪刀 2（羊毛 5、树叶/蛛网 15）；剑 1.5（蛛网 15、竹子 30）。
- 效率附魔：`+ level² + 1`（效率 V=+26），仅在正确工具类型时生效。
- 急迫（Haste）：`× (1 + 0.2×等级)`；挖掘疲劳：`× 0.3^min(level,4)`（I=0.3, II=0.09, III=0.0027, IV=0.00081）。
- 环境：水下/离地 ÷5（见 §1.4）。
- 硬性规则：**连续挖掘两个方块之间有 6 tick（0.3 秒）延迟**；单块预计 ≤0.05 秒则无延迟秒破。
- 实例：急迫 II + 效率 V 钻/合金镐挖石头（硬度 1.5）：(8+26)×1.4=47.6 > 1.5×30=45 → 秒破。

### 5.2 常用硬度（MW "Breaking" 硬度表）
| 方块 | 硬度 | 爆炸抗性 | 备注 |
|---|---|---|---|
| 基岩 | -1 | 3,600,000 | 不可破坏 |
| 黑曜石 | 50 | 1,200 | 需钻石镐 |
| 熔炉/发光石 | 3 / 0.3 | 6 / 0.3 | |
| 石头 | 1.5 | 6 | 木镐可收 |
| 圆石 2.0/矿石 3.0 | 6 | | 深板岩 ×2 硬度 |
| 泥土/砂/沙砾 | 0.5 / 0.5 / 0.6 | 0.5 | 徒手即可 |
| 木板/原木 | 2 | 3 | 斧加速，徒手可收 |
| 玻璃 | 0.3 | 0.3 | 掉落无物 |
| 树叶 | 0.2 | 0.2 | 剪刀/时运掉落 |
| TNT | 0 | | 瞬破 |

- **canHarvest（工具等级门槛）**：石头类需木镐+（等级 1）、铁/金矿需石镐/铜镐+（等级 2）、钻石/绿宝石/金矿需铁镐+（等级 3）、远古残骸需钻石镐+（等级 4）。不满足时：挖得极慢（÷100）且**无掉落**。

### 5.3 徒手可挖逻辑
- 徒手倍率 1；任何方块只要"所需等级 ≤ 0"（泥土类、木头类、沙土类等）徒手即可收获；等级不足时徒手挖石头 7.5 秒（1.5×5）且无掉落。
- 即挖即碎方块清单（硬度 0）：火把、花、蘑菇、TNT、庄稼、雪层、蛋糕等——瞬时破坏，无裂纹阶段。

### 5.4 挖掘"手感"细节（OpenCraft 需逐项对齐）
- **裂纹覆盖层 10 阶段**（destroy_stage_0..9），按累计破坏进度选取。
- **方块线框选中框**（黑色 wireframe，1.002 倍扩），每 tick 更新。
- 挖掘中**手部持续挥动动画** + 循环"敲击"音效（材质决定音色：石头/木/沙/草等十余种 sound group）。
- 挖碎瞬间：破坏粒子（按方块贴图）、方块掉落物带随机初速度弹出、无 6 tick 延迟时无缝连挖。
- 换目标或松手即重置进度（进度不跨目标保存）。
- 创造模式：**即点即碎**（无裂纹动画），无掉落物。

### 5.5 放置与到达距离
- **方块到达距离：生存 4.5 格、创造 5.2 格**（JE；基岩 5）。
- **实体交互（攻击）距离：3 格**（JE，`entity_interaction_range`）；创造 3.5? —— JE 中实体接触范围 3.0（生存）/3.5?（实际 JE：实体攻击范围 3 格，创造 6?）——按 MW "Breaking" 页只给出方块 4.5/5.2；**实体攻击范围以 MW "Attack" 为准：生存 3.0 格**。
- 放置规则：射线找到相邻面放置；被生物实体阻挡则放置失败；与自身碰撞的方块（除盔甲架、告示牌等非实心）不可放置进玩家体积；按住右键每 **4 tick（0.2 秒）** 尝试放置一次（首击立即）。

## 6. 攻击：冷却、伤害、暴击、击退（来源：MW "Damage"、"Sword"、"Axe"、"Knockback"）

### 6.1 攻击冷却（1.9 战斗系统）
- 冷却时间 `T = 20/attack_speed` tick：
  | 武器 | 攻速 | 冷却 |
  |---|---|---|
  | 剑 | 1.6 | 0.625 s |
  | 斧 | 0.8 | 1.25 s |
  | 镐 | 1.2 | ~0.83 s |
  | 锹/锄 | 1.0 | 1.0 s |
  | 三叉戟 | 1.1 | ~1.09 s |
  | 重锤（Mace） | 0.6 | ~1.67 s |
  | 徒手/其他 | 4.0 | 0.25 s |
- 伤害缩放：`multiplier = clamp(0.2 + ((t+0.5)/T)² × 0.8, 0.2, 1)`（t=距上次攻击/换手 tick 数）。附魔加成按同式但**线性**（不平方）。
- 充能 **84.8%** 为门槛：暴击、横扫、疾跑击退需达到；攻击条 UI（剑上方/准星旁）实时显示充能。
- 基础伤害（JE）：剑 木 4→下界合金 8；斧 7→10；三叉戟 9；重锤 6（坠落加成另计，可至 100+）；镐 2→6；锹 2.5→6.5；锄 1→4；徒手 1。

### 6.2 暴击
- 条件：下落中攻击（falling > 0）+ 冷却 ≥84.8%；伤害 **×1.5**。
- 禁止：水中、攀爬、缓降/失明状态、骑乘、飞行。
- 表现：目标身上**十字形棕色暴击粒子** + 变调音效。

### 6.3 横扫（Sweeping Edge，仅剑）
- 命中单个目标且无横扫粒子条件时对周围目标造成 `1 + sweepingLevel/level...` 实际：横扫伤害 = 基础伤害 ×(附魔等级+1)/（等级 I ⅓、II ⅔、III 100%），带横扫粒子烟雾。

### 6.4 击退（来源：MW "Knockback"、"Damage"）
- 基础攻击击退：水平约 0.4 格/tick 初速（水平 0.4 + 垂直 0.4 量级，随目标速度阻尼衰减）。
- **疾跑击退**：疾跑命中额外+0.5 水平（可将目标击退更远），需冷却 ≥84.8%。
- 击退附魔：每级 +1 水平（最高 II）；击退抗性属性可完全减免。
- 受击相机表现：目标视角被"撞离"锁定方向一瞬（红色受击闪 + hurt camera tilt）。

## 7. 物品与库存（来源：MW "Inventory"、"Item (entity)"、"Ender Chest"、"Chest"）

- 玩家库存：**4 盔甲 + 27 主储物 + 9 快捷栏 + 1 副手**；随身 2×2 合成格。
- 大箱子 54 格（双箱）、箱子 27、木桶 27、潜影盒 27（可整盒搬运）、**末影箱 27**（跨维度独立、不可被爆炸破坏）。
- 堆叠上限：一般 **64**；部分 **16**（雪球、鸡蛋、末影珍珠、告示牌等）；工具/盔甲等 **1**。JE 数据组件可改（最大 99 显示规则）。
- 掉落物实体：
  - **5 分钟（6000 tick）消失**（区块加载才计时；玩家投掷 2 秒拾取延迟、自然生成 0.5 秒）；
  - 合并：0.5×0.25×0.5 包围盒内同类合并，大堆保留原剩余时间；
  - 受重力+地面摩擦，水中浮起、被水流/活塞推动；
  - 下界合金耐岩浆、下界之星防爆。
- 耐久：每次有效使用 -1；剩余耐久以工具条显示（颜色绿→红）；铁砧可修（经验+材料）；**经验修补（Mending）**用拾取 XP 修复（1 XP≈2 耐久）。
- 附魔系统概览：
  - 附魔台：30 级上限需求、3 青金石、3 档位（1–10/11–20/21–30），书架 15 个封顶（排布规则：距台 1 格斜向、等高或高 1 格）；公式见 §来源 "Enchanting mechanics"（含 enchantability 修正与多词条概率 eCost/50）。
  - 附魔亲和（enchantability）：金 22/25（最高）、木 15、铁 14、钻 10、石 5。
  - 铁砧：合并/修+改名，**prior work penalty 每次翻倍**（2^n 经验惩罚）；上限 39 级。
  - 宝藏级附魔（修补、冰霜行者、灵魂疾行、横扫之刃?（非宝藏）…）只能 loot/钓鱼/交易/附魔书；诅咒类同理。
  - 互斥组：四种保护、锋利/亡灵/节肢、时运/精准采集、无限/修补、激流/引雷+忠诚、深海探索者/冰霜行者。

### 7.2 铁砧与修复（MW "Anvil"）
- 合并两件同名装备：耐久取"较高者 ×1.12 + 较低者"（上限为满值）再收取附魔合并等级费用。
- 改名一次 1 级；prior work penalty：每经过一次铁砧（含附魔书合成）费用倍增（2^n）——一件装备最多约 5-6 次铁砧操作后费用超 39 级无法再用（创造除外）。
- 经验修补：拾取的每个 XP 球先补装备耐久（1 XP = 2 点耐久）再进经验条。

### 7.3 盾牌
- 右键格挡：减免来自正面的大部分伤害（含爆炸/箭），有 **5 tick（0.25 秒）** 拔盾延迟；斧攻击可击晕盾牌 5 秒（100 tick）；盾牌自身 336 耐久。

## 11. 进程结构（进度线，来源：MW "Tutorials/Advancement guide"、官方进度 "Advancement"）

1. **徒手/木器期**：撸树 → 木板/木棍 → 工作台 → 木镐 → 挖石 →石器全套（石器解锁挖铁矿）。
2. **石器→铁器**：找到铁矿（一般 Y 0–64，山地下更富）→ 熔炉烧铁 → 铁镐/铁剑/桶/盾 → 铁盔甲。
3. **钻石期**：钻石矿 Y -59 附近最富（深板岩层）；需铁镐；出钻石镐/剑/盔甲 → 顺带黑曜石（需钻石镐，水+岩浆浇铸或天然）。
4. **下界**：黑曜石 10 块搭门 → 下界要塞找烈焰人（烈焰棒）+ 下界疣 → 回主世界：附魔台（书+钻石+黑曜石）、酿造台、末影之眼（烈焰粉+末影珍珠）。
5. **末地**：12 只末影之眼定位要塞、填 12 帧末地门 → 末影龙战（见 §10.4）→ 末地城/鞘翅（潜影壳潜影盒）。
6. **下界合金期**：下界挖掘远古残骸（Y 8–22，爆炸开采）→ 4 残骸+4 金锭=1 合金锭 → 锻造模板升级钻装 → 合金全套。
7. **凋灵与信标**：凋灵骷髅头 ×3（下界要塞刷）→ 凋灵 → 下界之星 → 信标（基座矿物方块）。
8. **支线**：

## 13. "对齐手感"最关键机制点（OpenCraft 实现优先级建议）

1. **Tick 级物理 + 阻尼模型**：0.08/tick² 重力、0.98 阻尼、0.42 初跳速 → 才能复现 1.25 格跳跃、78 m/s 终端速度、跳跃弧线与"空中漂"感；帧率无关地按 20 TPS 模拟。
2. **挖掘反馈三件套**：每 tick 累计破坏进度（精确公式 §5.1）+ 10 阶段裂纹贴图 + 材质音效循环与手部挥动；6 tick 连挖延迟；选中线框。这是 MC "手感"辨识度最高的部分。
3. **1.9 攻击冷却**：0.625 s 剑冷却、(t+0.5)/T² 缩放、84.8% 暴击/横扫门槛、攻击条 UI——没有它 PVE/PVP 手感完全走样。
4. **饥饿-饱和-耗竭三层模型**：饱和度决定回血速度（§3）→ 食物价值分层成立；疾跑耗竭把"跑"变成资源决策。
5. **受击反馈**：0.5 秒无敌帧、击退水平/垂直分量、疾跑击退、hurt camera tilt、暴击十字粒子、音效变调——打击感全在这组参数。
（次级但重要：疾跑 FOV 拉伸、潜行防坠落、掉落距离 HUD 无显示但音效分层、方块放置 0.2 秒重复、掉落物 0.5 秒拾取延迟与磁吸半径约 1 格。）

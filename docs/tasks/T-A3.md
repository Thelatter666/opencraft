## 3. 交付物 A：美术规格 v1（新建 `docs/art/01-style-guide.md`）

内容须覆盖（这是**规格**，不是过程日志）：

1. **画布与网格**：16×16；像素必须落在整格上；不得出现抗锯齿灰边（像素风的基本纪律）。
2. **色板**：给一个**限定色板**（建议 ≤32 色），写明每个色的用途分类
   （土系 / 石系 / 植生 / 木 / 水 / 玻璃透光 / 矿石点缀 / UI）。
   ⚠ **起点参考**：现有程序化色板在 `game/client/src/atlas.cpp:46 base_color()`
   （如 dirt `{100,76,60}`、grass `{96,146,78}`、stone `{128,128,133}`）。
   **可参考但不受其约束**——它是"占位期间凑出来的"，你有权重定，但须在文档里说明
   **哪些是沿用、哪些是重定、为什么**。
3. **低饱和原则**：本项目视觉基调为低饱和（现有代码注释 self-described
   "Low-saturation base palette"）。规格须给出**可执行的判定**（例如饱和度上限），
   而不是仅写"要低饱和"。
4. **构图语言**：噪点/条纹/格纹/边缘处理的一套约定，使不同方块看起来**同属一个世界**。
5. **三面关系**：`_top` / `_side` / `_bottom` 之间的约定（例如 grass_block 侧面要有
   顶部绿边；log 顶底是年轮、侧面是竖纹）。
6. **透光资产的 alpha 约定**：water / glass / leaves 如何处理 alpha
   （不透明资产一律 255）。
7. **命名与落点**：`<block_id>_<slot>.png`（见 `assets/README.md` §1，不重述）。
8. **自查清单**：交付每张贴图前要过的检查项（格式/尺寸/朝向/alpha/色板/原创性）。

⚠ **禁止**在规格里写"对齐 MC 某方块的外观"。本项目对齐的是**行为**，
外观必须原创（`docs/04` 红线 5）。可以对齐的是**风格类别**（16×16、低饱和、像素风）。

## 4. 交付物 B：首批方块贴图

### 4.1 范围（先说清口径）

⚠ **口径提醒（PM 已核）**：`BlockRegistry::size() == 21`（**air 也在 defs_**），
但 `register_block` **实际调用 20 次**（`engine/voxel/src/block_registry.cpp:26-45`）。
⇒ **需要贴图的方块是 20 个**，不是 21（air 不产生瓦片）。

**首批不做全部 20×3=60 张**（量太大、会拖慢首卡）。建议分批，首批建议覆盖下面两组，
理由是它们构成了新玩家视野的主体：

| 组 | 方块（字符串 id） | 说明 |
|---|---|---|
| **地表组**（建议首批） | `grass_block`（top/side）、`dirt`、`stone`、`sand`、`log`（side/top）、`leaves`、`planks`、`water`、`glass` | 出生点周边视野的绝大部分 |
| **矿石组**（建议首批） | `coal_ore`、`iron_ore`、`gold_ore`、`diamond_ore`、`copper_ore` | 五种做法同质（石头底 + 矿点），是"一份方法论 ×5"的典型批量对象 |

其余（`cobblestone`/`gravel`/`sandstone`/`bedrock`/`snow_block`/`obsidian`）列为**第二批**，在规格文档里登记待办。

**每张贴图的三面**：`_top` / `_side` / `_bottom` 三张齐全才算一个方块完成
（`assets/README.md` §1 的 slot 表）。若某方块三面相同，仍需三份文件（或一个来源三份输出，
由你决定并在规格里写明约定）。

### 4.2 每张贴图的要求

- **正好 16×16 PNG**（`assets/README.md` §2：不符会被拒绝并回退，**不缩放**）
- **朝向正确**：PNG 第 0 行 = 面的上沿（拿不准就画个上下不对称的试探图案）
- **色板受 `docs/art/01-style-guide.md` 约束**
- **`CREDITS.md` 每条一行，六字段齐全**（来源/工具/提示词摘要/日期/人工后处理）

### 4.3 ★ 合规三条硬规则（逐字见 `docs/05 §2`，本卡不再改写）

1. **AI 输入禁止含 MC 资产**——不得把原版贴图/截图/官方美术喂给模型做参考重绘。参考只能给**文字描述**。
2. **提示词不得点名 MC**——不得出现 "Minecraft-style" 等。
3. **证据链照旧**——AI 生成不豁免留痕。

⚠ 若**没有**使用 AI（纯手绘），`工具` 写软件名、`提示词摘要` 写"无"。如实即可。

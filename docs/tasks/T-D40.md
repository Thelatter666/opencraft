# 任务 T-D40：抽取公共 `sweep_move`（消除第三份碰撞代码）

里程碑：M2c 地基（**排在生物卡 T-M2 之前**）　前置：**T-E1**
基线：**359/359**。运行前请先跑基线确认。
卡面落盘日期：2026-09-17（PM）

---

## 目标（一段话）

把 `engine/physics` 里**私有**的体素碰撞原语（`Box` / `box_collides` /
`highest_surface_below` / 逐轴扫掠 `move_axis_*`）暴露为**公开可复用接口**，
让客户端物理与权威侧实体**共用同一份**，消除当下的重复，并防止生物卡再造第三份。

## 为什么（开发者在 T-E1 报告中提出，PM 采纳并提高优先级）

T-E1 开发者指出：

> 碰撞代码与 `engine/physics` 重复，**建议下次开物理层时抽公共 `sweep_move`，
> 否则生物卡会再造第三份。**

PM 核查确认重复真实存在：

| 函数 | physics 侧 | 实体侧 |
|---|---|---|
| `box_collides` | `player_physics.cpp:32`（**私有**） | `item_sim.hpp:201`（**复制一份**） |
| `highest_surface_below` | `player_physics.cpp:57`（私有） | `item_sim.hpp:225`（复制） |
| `move_axis_y/x/z` | `player_physics.cpp:~212`（私有） | `item_sim.hpp:254`（复制） |

**两个 `Box` 结构字段完全相同**（均为 6 个 `double`，同顺序）：
- physics 的 `Box`（`player_physics.cpp`，匿名 namespace 内）
- 实体的 `EntityBox`（`item_sim.hpp`，`item_detail` namespace 内）

⇒ **重复的根源**：这些函数在 physics 里是 **.cpp 内部函数，头文件未暴露**，
实体侧拿不到，只能复制。

这与本项目一直在避免的"**双重真相源**"是同一个问题：
碰撞语义若两处各写一份，任何一处的修正都不会自动传到另一处
（例如 T-D8 引入的"高度感知"语义——目前靠两边都记得改才一致）。

**为什么排在生物卡之前**：生物卡（T-M2）必然要再做一套实体移动。
若那时还没抽公共，就会变成**第三份**碰撞代码。

## 接口契约

### ★ 本卡的核心判据：行为零变化

碰撞语义**逐字节保持一致**。这比"代码更干净"重要得多——
碰撞是玩家每 tick 都在感受的东西，任何细微变化都会变成手感回归。

### 锚点（**用符号定位，不写死行号**）

| 项 | 符号 |
|---|---|
| physics 私有 Box | `engine/physics/src/player_physics.cpp` 匿名 namespace 内的 `Box` |
| physics 碰撞函数 | `box_collides` / `highest_surface_below` / `move_axis_y|x|z` |
| 实体侧复制 | `game/server/sim/include/opencraft/sim/item_sim.hpp` 的 `item_detail::EntityBox` / `box_collides` / `highest_surface_below` / `move_axis_*` |
| 世界查询契约 | `physics::IBlockSource`（`solid_at` / `shape_top_at` / `liquid_at`）—— **不得改动** |
| 实体定义 | `game/common/include/opencraft/game/entity_type.hpp` |

⚠ 行号会漂，一律 `grep` 定位。

### 设计约束

- 公共接口**依赖 `IBlockSource` 即可**，不要让 physics 反过来依赖实体层
  （依赖方向必须是：实体 → physics，不能倒过来）。
- `Box` 用 `double`（现有两份都是 double，保持一致）。
- 保持**逐轴分离滑动**（Y → X → Z）与既有子步语义。

## 6. 设计与制作（卡面 §3 的四条边界）

### 6.1 意象 → 几何（原创性：红线 2/5）

**轮廓与配色未参照任何原版生物模型或贴图**，全程 **未用 AI**、未把任何既有作品喂给模型；
形体是**从意象自己拆的几何**（"空洞苦役 / 枯槁者"）：

| 意象（卡面 §3.1） | 拆成的几何 |
|---|---|
| 细长四肢 | 腿：x=1 / x=4 各一列，**1 格宽 × 2 格深、0.9 格长（占全高 50%）**；臂：x=0 / x=5 各一列，**1 格宽、0.9 格长**，肘部往前折一格、垂在身前 |
| 前倾驼背 | 肩背一整条 4 格宽 3 格深、且**整个偏后**（y 0..2）+ 其上一层 2×2 的**驼峰顶**（z=14）；腰胯只有 2 格宽 2 格深 ⇒ 侧视是"背弓起来" |
| 锁骨下陷的空洞感 | z=11 那一层把**正面那一格整块挖掉**，露出后排的近黑面（躯干第二色，索引 9）⇒ 正面是锁骨下 2×1 的黑洞，**侧视轮廓也真有一道缺口**（是凹、不是穿） |
| 低垂的头 | 颈从**胸口前沿**伸出（比肩线还前 1 格），颅骨 4×4×3、整颗压在肩线之上一点点（头底 z=15 vs 肩顶 z=13）⇒ 头是**探出去、垂下去**的，不是坐在肩上 |

**配色决策**（全部取自 §2.1 的 32 色表，未新增表外色）：
主体是**冷灰石系**（S0 暗 / S1 中 / S2 亮灰 / S5 近黑）——对应它在代码里的占位形象"灰岩怪"
（`inventory_wiring.hpp` 的 stand-in 注释：a Hollow Wretch is grey rock）；
**颅骨与手是漂白的骨色（S4 / S3）**，眼窝是**全模型最暗的 O0**，背脊一道 **E0 锈斑**（脊椎上的旧伤）。
⇒ 一颗**白颅骨压在一具灰石枯躯上**：远看先读到"点着两个黑洞的头"，再读到"瘦长的身子"。

### 6.2 坐标与契约（①②③）

|---|---|
| 网格 | x 0..5（6）× y 0..5（6）× z 0..17（18）；**1 体素 = 0.1 格**（z 跨度 18 ⇒ 缩放 = 1.8/18，整数） |

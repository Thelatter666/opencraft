## 3. 六条裁决（PM 已裁，照做）

### C-1 攻击输入改为**点击触发（边沿）**，任意时刻可挥，挖掘不变

现状"按住左键 + 12 tick 二值门"必须改，因为：**只要 gate ≥ T，斜坡公式就是死代码**
（每次挥击 t≥T ⇒ 恒满充能）。三条路里选原版口径：

- **采纳**：左键**边沿触发**（rising edge）即挥击，**任何时候可挥**，伤害按 t 走斜坡（最低 0.2 档）；
  连点快了伤害就低——这是 1.9 战斗"点击节奏"的本义（`research/01:384`："没有它 PVE/PVP 手感完全走样"）。
- **挖掘完全不受影响**：挖方块仍按住持续（`tick.cpp` 现有挖掘路径零改动）；
  生物在准星前时挖掘仍被挂起（`mining.reset()` 现状保持）。
- ⚠ 输入手感变化点要在报告里显式写一段（真人验收时确认：连点低伤、按住不连击是预期，不是丢键）。
- 有边沿触发的现成先例：容器倒/舀（`tick.cpp` 水桶分支即边缘触发）。

### C-2 充能记账：**权威侧记 `last_attack_tick_`，从未攻击 = 满充能**

- 权威侧：`WorldSim` 增 `std::uint64_t last_attack_tick_`（sentinel = 从未攻击 ⇒ **首击满充能**）；
  `apply_attack` 接受挥击时记 `tick_counter_`。t = `tick_counter_ - last_attack_tick_`。
  ★ **"从未攻击 = 满充能"是保住存量测试零翻转的关键**——现有测试直接构造 `ActionRequest` 调
  `submit`，都不带攻击历史，若首击按 t=0 算（20.8%），一堆断言会翻转。
- 客户端镜像：`InteractionState.attack_cooldown`（12 tick 倒计时）**替换**为充能记账
  （如 `attack_age`：距上次挥击的 tick 数；死亡/重生清回"未攻击"）。客户端只喂 UI 与输入，
  **伤害判定以权威侧为准**（客户端不传 t——权威侧自己会算，M3 网络化时这就是预测/和解的一部分）。
- **换武器即换 T**：T 由 `req.actor.held_item` 当场查 `ItemDef::attack_speed` 得出，不缓存。

### C-3 `ActorPose` 增 `sprinting` / `falling` 两个声明字段（协议扩展）

- `bool sprinting`（客户端从 `PlayerState::sprinting` 抄）与 `bool falling`
  （**定义写死**：`!on_ground && velocity.y < 0.0`，在 `actor_pose()`（`tick.cpp:78`）里填）。
- 信任模型与 `held_item` 完全同构（`protocol.hpp:109-114` 注释先例：客户端声明、权威侧在
  产生世界影响处使用；M3 上收/校验）。权威侧用它们做暴击与疾跑击退的判定输入。
- `protocol.hpp` 本卡**允许改**（T-D46 禁它是当时不涉及；本卡的 ActorPose/ActionRequest 注释
  要同步更新，特别是 `:71-72` 那句 "still later work"）。

### C-5 疾跑击退：0.4 → **0.9**（0.4+0.5），门槛 = 充能 ≥84.8%

- 判定写在权威侧 `apply_attack`：`m(t) >= 0.848 && req.actor.sprinting` ⇒ 本击击退初速 0.9，
  否则 0.4（**非疾跑路径逐字节不变**——T-D46 的 0.4 系用例预期零翻转）。
- `knock_back`/`push_away` 签名不动，改调用点传值；两侧常量注释的 ⚖ 数字同步。
- 总位移账（T-D46 口径：阻尼在位移后，几何级数 `v0/(1−0.91×0.6) = v0/0.454`）：
  0.9 ⇒ **≈1.98 格**（对照 0.4 ⇒ 0.881）。实测会略小（动量截断吃尾部），单测给区间即可。
- T-D57② 的"不减半叠加"口径**继续适用**（本卡不改叠加方式）。

### C-6 生物侧 20 tick 攻击间隔**不动**

`MobDef::attack_cooldown = 20`（`mob_type.hpp:148`）是 T-M2 验收过的实现，`research/01` 没有
生物攻速表依据——**不引入"玩家按攻速、生物按攻速"的双轨对齐**，生物侧维持 1 次/秒。
若将来有原版依据，另开校准卡。

### 4.1 权威算例（PM 已算，可直接写成断言；公式 = `m(t) = 0.2 + ((t+0.5)/T)²×0.8`）

**剑 T=12.5**：t=10 → **76.45%**；t=11 → **87.71%**（越过 84.8% 门槛的最小整数 t）；
t=12 → **100%**（全额最早点）。门槛连续解 t=10.75，整数取 11。

**徒手 T=5**：t=0 → **20.8%**；t=1 → **27.2%**；t=2 → **40%**；t=4 → **84.8%**（恰好达门槛）。

**杀 20 血 Wretch**（每击间隔 = 达门槛最小 t）：

| 武器 | 击数 | 节奏 | 总耗时（冷启动，击点 11/22/…） |
|---|---|---|---|
| 徒手 1.0（现状） | 20 | 12 tick/击 | 240 tick = 12.0 s |
| 木剑 4.0 | **5** | ≥11 tick/击 | **55 tick = 2.75 s**（热启动 44 tick） |
| 木剑暴击 6.0 | **4** | 同上 | 44 tick = 2.2 s |

**疾跑击退**：0.9 初速 ⇒ 总位移 ≈ **1.98 格**（= 0.9/0.454；对照 0.4 ⇒ 0.881，实测略小因动量截断）。

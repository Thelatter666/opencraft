## 目标
20 TPS 固定步长的玩家物理模拟：逐轴 AABB+子步的体素碰撞（贴墙滑动）、
地面移动三档速度、跳跃、重力/阻尼/终端速度、摔落伤害、潜行边缘防坠落、
水中行为（浮力/减速/摔落重置）。输入用抽象 `InputState`（前进/左右/跳/潜行/疾跑的
布尔+视线朝向角），不依赖 GLFW。

## 接口契约（冻结项）
- 命名空间 `opencraft::physics`。
- `PlayerState`：位置（脚底中心，double）、速度、on_ground、fall_distance、
  朝向 yaw/pitch、姿态（站/潜行）；体形常量：站立 AABB 0.6×1.8、潜行 0.6×1.5
  （碰撞盒不随视角变化）。
- `step_player(PlayerState&, const InputState&, const IBlockSource&, const PhysicsConfig&)`
  ——恰好推进 1 tick（50ms）；`IBlockSource` 为 `bool solid_at(int wx,int wy,int wz)`
  最小接口（测试可用假世界，运行时适配 ChunkManager+registry）。
- `PhysicsConfig`：所有可调常数集中于此，默认值=规格值并注释来源；黄金测试用默认值。
- 输入序号化预留：`InputState` 带 u32 sequence 字段（网络预测 T 后续要用，现在只透传）。

## 数值/规格依据（docs/01 §2 的 ⚖ 全表）
- 行走 4.317 m/s、疾跑 5.612、潜行 1.295；跳跃初速 0.42 格/tick、跳高 1.2522 格；
  重力 0.08/tick²、垂直速度阻尼 ×0.98/tick、终端速度 ≈78 m/s；
  摔落伤害 floor(fall_distance − 3) HP；水/梯重置摔落；
  受击无敌帧 0.5s 留字段不实现（无战斗系统）。
- 实现模型：tick 级"加速度+阻尼"积分（research/01 §1.1 的 v = (v·r) + a 概念），
  通过调 a 与 r 使稳态平均速度命中上表（单 tick 位移 = 表值/20）。你的推导过程
  （含 chosen a/r 与验证）写进报告——这是"数值即规格"的留痕要求。

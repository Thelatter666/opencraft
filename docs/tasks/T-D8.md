## 关键实现要点（research/06 §6.3，易错）

MC 的跨步流程是：

```
1. 先用扁平尝试（不跨步）求解，得到水平距离 d_flat
2. 收集所有候选抬升高度（≤ maxUpStep 的 Y 面），升序排序
3. 逐个高度重试完整求解，取第一个产生更大水平距离的结果
4. 返回该结果，并下落回原地面高度
```

★ **关键性质（必须做对）**：选择的是**能带来增益的最低高度**，而非最高高度。
因此实体可以跨上形状的**内部台阶**，而不只是顶面。取最高会得到错误行为。

其他注意事项：
- 跨步发生在**水平碰撞之后**（research/06 §6.2 第 4 步："若 onGround 且发生水平碰撞 → 尝试跨步"）
- 只有 `onGround` 时才跨步（空中不跨）
- 下落回原地面高度，不要留在抬升后的悬空位置

## 目标
实现纯函数化的地形生成器：给定（种子, 区块坐标）→ 填充一个空 Chunk。
包含：主噪声 3D 密度+高度偏置地形、海平面 Y=63 水填充、基本洞穴（奶酪洞+意面洞两类
简化版，入口可达地表不强制）、地表规则层（草/土/石分层、水下变体沙/砂砾）、
基岩层渐变（Y=-64 全基岩 → Y=-59 消失）。本任务不接区块流式加载（那是 T009 状态机），
只交付"可调用、可测试"的生成器。

## 接口契约（冻结项）
- 命名空间 `opencraft::worldgen`；`TerrainGenerator(uint64_t seed, const BlockRegistry&)`。
- `void generate_chunk(int64_t cx, int64_t cz, Chunk& out) const`——纯函数：
  不读全局状态、不持可变缓存、重复调用结果逐字节一致；线程安全（可并发调用）。
- 种子派生：不同子系统用"世界种子 + 固定常数偏移"派生独立噪声种子（地形/洞穴各一路），
  常数写死在代码里并注释。
- 确定性硬要求：**只用 FastNoiseLite 的确定性 API**；最终参与黄金测试的哈希只对
  "方块 ID 数组"计算，禁止对浮点中间量哈希。

## 已知风险与提示

- 洞穴与地表穿透（洞口开在天上/水下）不要求处理完美，但不得产生"水悬空在洞里"的

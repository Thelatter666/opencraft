## 接口契约（冻结项）
- 命名空间 `opencraft::render`；库 target `opencraft_render`（链 opencraft_voxel/core）。
- 网格化入口（纯函数，线程安全）：
  `MeshData build_chunk_mesh(const IBlockSource& blocks, ChunkPos pos)`——
  `IBlockSource` 是最小接口 `u16 block_at(int wx,int wy,int wz)`（世界坐标），
  由调用方适配 ChunkManager；meshing 内部不得持有全局状态。
- `MeshData`：按"不透明/半透明"两桶分离的顶点+索引；顶点格式压紧
  （区块内局部坐标 u8/u16 + 图集 tile 索引 u16 + 预留光照字节），具体布局自定并注释。
- 纹理图集：程序化生成的原创占位纹理（每方块顶面/侧面/底面各一 tile，16×16，
  用简单程序图案+按方块类型区分的低饱和配色）；⚠️ 合规红线：不得模仿 Minecraft
  具体纹理的构图/配色/噪点分布——抽象图案即可，正式美术资产后续里程碑另做。
  块内 UV 收缩 ≥0.5px 防渗色。

1. `art_source.py` 内建的构图自检（报告"最大同色正方形边长 + 违规坐标"）与饱和度自检；

两者都只**报告违规位置**，不生成像素、不含随机数。它的作用是让"我画的图是否满足规格"
可被机器复核 —— 与 T-A3 用导出脚本自检饱和度是同一类做法。清单里的 `03_art_source_run.txt`
就是 1 的原始输出。

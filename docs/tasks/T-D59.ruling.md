## 1. PM 独立读回（非转述报告）

1. **公式**：`attack_charge_multiplier`（`protocol.hpp:87`）逐字实现 `0.2 + ((t+0.5)/T)²×0.8`，
   `T = 20/attack_speed` 为 double（**镐 16.666… 未取整**，有专测 `the pick's T is 16.666…`）。
2. **记账**：权威侧 `last_attack_tick_` + sentinel `kNoAttackTick` = **从未攻击满充能**——
   实机日志 `age -1 → charge 1.000` 直接可见；**拒绝路径不耗充能**（`last_attack_tick_` 在全部
   拒绝 return 之后才写，有专测 `a refused swing costs no charge`）。
3. **门槛与暴击**：`>= kAttackChargeThreshold`（0.848）；`crit = falling && charged`——
   `falling` 定义在 `actor_pose()`（`tick.cpp:92`）为 `!on_ground && velocity.y < 0.0`
   （上升段不算，专测 `the falling flag is the descent`）。
4. **疾跑击退**：`kSprintKnockback = kAttackKnockback + kSprintKnockbackBonus` 且
   **`static_assert(== 0.9)`**；非疾跑路径常量 `kAttackKnockback = 0.4` 一字未动（T-D46 用例零翻转）。
5. **武器解析**：`req.actor.held_item` 每挥查表（换武器即换 T，有专测）；`attack_damage_of`/
   `attack_speed_of` 的 0.0 fallback **只有一处**（item_registry.hpp 的 accessor）。
6. **输入**：`left_clicked = left_held && !prev_left`（边沿，与水桶分支同构）；挖掘仍读
   `left_held` 持续——**`mining.*` 与挖掘路径 0 行 diff**。
7. **充能条**：HUD 画 232px 条 + 门槛刻度，客户端 `attack_charge()` 与权威侧同公式同常量
   （`protocol.hpp` 一份拷贝——两端不可能漂移的设计）。

## 2. 判定逻辑（`auto_jump.hpp`）

### 2.1 门限矩阵（research/08 §2.1）

按文档顺序短路，全部在做体素查询之前：开关关闭 / 非接地 / 潜行 / 非正向
（`!in.forward || in.backward`）/ 在水中（与物理模块 `is_in_water` **同一对探针**：
脚部层与半身层，`liquid_at`）/ 骑乘（M2 无载具系统，**必然满足，见 §4 #1**）。

### 2.2 几何（research/08 §2.2）

三层盒判定，**只用 `solid_at`**（全方块；部分高度属 step-assist 与 M2 内容，见 §7.2）：

1. **脚部探测**：身体盒沿移动方向扫 `scan_distance`，与扫描盒严格重叠
   （面贴面不算接触，与 `box_collides` 同约定）；不重叠 ⇒ 前方无阻挡 ⇒ 不跳。
2. **高度窗口**：取"最先撞上的那一列"（按该面法线轴的距离最小），
   `ΔH = 柱顶面 − 脚高`；`cfg.step_height < ΔH ≤ max_obstacle_height` 才跳。
   **下界取实体自身的 `PhysicsConfig::step_height`**（卡面建议的结构体里写的是
   `min_obstacle_height = 0.6` 常量，但那样 Mob 配置会失效——本卡按 T-D7
   "参数按实体类型实例化" 契约改为读 `cfg`）。**只判最近一列，不回退到更远列**：
   跳不过去的那列就是玩家正面对的列，跳过它去为更远的列起跳只会白跳。
3. **净空**：落脚面为障碍顶面，身体盒（**当前 x/z 足迹**，非扫描盒）在
   `[顶面, 顶面 + clearance_height)` 内不得命中原石 ⇒ 撞头/倒挂楼梯一律不触发。

### 2.3 贴墙否决（research/08 §2.3）

单位移动方向与**被面对那一列**的面法线（轴对齐）的分量即 `|cos θ|`；
小于 `wall_normal_epsilon`（0.05）⇒ 判为贴墙侧移，**否决且立即返回**
（不是过滤器而是否决位）。该否决**只作用于最近的那一列**，因此"贴着侧墙走向正前方的
1 格坎"仍会正常起跳（已用单测固定：flush 沿墙走 `false` / 同位置正面走 `true`）。

### 2.4 注入（卡面 §3）

```cpp
if (!in.jump && auto_jump_enabled) {
    phy::AutoJumpConfig aj_cfg;
    if (phy::should_auto_jump(curr_state, in, world, phy::PhysicsConfig{}, aj_cfg)) in.jump = true;
}
```
**不写 `state.velocity.y`**；让 `player_physics.cpp:545` 的既有分支执行——所以
疾跑 `sprint_jump_boost = +0.2`、起跳顺序（先设速度后位移）、落地减速全部天然一致。
玩家自己按空格时短路（`!in.jump`），永不改写玩家输入。

## 7. 须上报的两项 + 接缝登记

### 7.1 暂停菜单命中坐标：帧缓冲像素 vs 内容像素（**本卡顺手修正**）

原代码 `glfwGetCursorPos(&mx,&my)` 得到的是**内容像素**，而按钮布局/正交投影用的是
`fb_width/fb_height`（**帧缓冲像素**）。**本机是 1x 缩放**（实测 `system_profiler`：
`Resolution 1920x1080` + `UI Looks like 1920x1080`，窗口截图像素 = 1280×748 = 窗口点数），
二者相等，故**本机行为逐位不变、无法在此验证修复效果**。
在 HiDPI（backing scale 2）上二者差一倍，悬停区会整体落在窗口右半屏之外 ⇒ 点不中。
本卡在暂停菜单内统一换算一次（`win_w/win_h` → `fb_width/fb_height`；1x 下换算因子为 1，
不改变任何既有行为）。

**请 PM 裁决**：这属"未在 HiDPI 上验证的潜在缺陷修复"。若 PM 手边有 Retina 机器，
一次真人点击即可判定；判定失败则回滚这一处（与 Auto-Jump 无关的独立 hunk）。
（补充：本机 1x 下**真实鼠标点击已验证可用**——见 §5.5，按钮点击能正确翻转开关，
故至少"点击→命中判定→动作"这条链在 1x 上是通的。）

### 7.2 Auto-Jump 对部分高度方块是盲区（**设计选择，请 PM 知悉**）

`solid_at` 对 `BoxWorld::partial()` 类方块返回 false（部分高度不属于"实心"），
故本判定**看不见半砖/地毯**。后果：卡面验收 #2 的 "0.5 格不触发" 是由
"该方块不在实心集合"达成，而非由高度窗口下界达成（下界由 Mob 用例真正断言）。
产品侧含义：**这符合预期**——≤0.6 的高差由 step-assist 负责且不掉速，
Auto-Jump 不该为它起跳；但 M2 引入部分高度方块后，"Auto-Jump 是否应越过 0.6–1.0

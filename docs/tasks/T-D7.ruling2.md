## 裁决 1：采样口径 → **采纳链式口径（连续跳跃链）**

**采纳开发者判断。** 依据三条：
1. wiki 原文表头 "Average speed" + "Running start effective? **No**" + 脚注 "every jump"
   三处一致指向**连续跳跃链**而非孤立弧。
2. **决定性证据**：链式口径下 MC 原始 **+0.2 精确命中 7.1268**（偏差 0.003%）；
   而冷弧口径下同为 +0.2 只得 **6.05**，需 +0.33 才能凑到。
   `+0.2` 是 MC 的机制常数（多来源一致），能自然命中的那个口径才是正确语义。
3. 反过来说：若 7.127 是冷弧语义，则意味着 MC 的 +0.2 是错的——这不成立。

**结论**：T-D1 的 `0.1842` 是在**错误口径**（冷弧）下凑出的数，已被本卡证伪并退役。
这不是 T-D1 的过失（当时无链式证据），而是口径信息在 T-D1 时点不可得。

## §0 ★ PM 独立复核：**他对我的推翻成立，我错了**

他说我"MagicaVoxel 官网未列明许可"的结论是错的。**我必须自己验，不能因为他给了证据就采信，
也不能因为是我自己的结论就护着。**

### 我的第一次独立核验：**没验到**（差点误判他错）

```
curl -x http://127.0.0.1:7890 "https://ephtracy.github.io/"  → 4326 字节
grep -io "licen" → 命中数: 0
```

**我差点据此认定他编造。** 但我停下来了，因为这正是我自己在记忆里写过的规矩——
「**用 grep 判"某信息是否缺失"前，先换 2-3 种检索式验证检索式本身有效**」。

### 第二次核验：换 URL 后**验到了，他是对的**

根页面只是 4326 字节的 JS 框架（`.mv_load_content` 动态加载正文），
真内容在 `mv_main.html`。我独立拉取原文：

```
License
  Free to use for any project.
  Credits to the software are appreciated.
  Selling or distributing the software (original or modified) in other packages are disallowed.
```

来源：`https://ephtracy.github.io/mv_main.html`，访问 2026-09-18，PM 本机 curl 独立取得。

### 裁定

| PM 原结论 | 现裁定 |
|---|---|
| 「MagicaVoxel 软件许可未核到，不得默认 CC0」 | **推翻。许可存在。** 三条：免费用于任何项目 / 鼓励署名 / 禁止转售或再分发软件本体 |

同时他的两点补充也成立：
- 我的 `LICENSE.txt` 404 复核**本身没错**（那个 URL 确实 404，我也复现了）——
  **错的是我"404 ⇒ 无许可"的推论**。404 的是那个 URL，不是许可本身。
- 发行包内确实无 LICENSE 文件（只有 `readme.txt` 第三方署名）——他也核了。

> **PM 教训（入 lesson）**：**"404"只证明该 URL 不存在，不证明目标信息不存在。**
> 我在 T-R2 因 grep 检索式错误伪造过"信息缺失"（`2L+7` 案），这是**同一类错误的第二次复发**：
> **用工具的"没找到"代替了"不存在"**。凡"未核到"结论，须换 ≥2 种检索路径再下。

## 建议表处置（R-1..R-14）

### R-1..R-8（主方案 / 路径 / 调色板通道 / 动画契约 / 自写加载器 / 渲染边界 / 回退表）—— **全部采纳**

逐条采纳，落点为**后续实现卡的接口契约**（PM 不在此处重复文档内容）。其中三条 PM 特别认可：

1. **Q3 的动画契约**（朝向/位置/受击/蓄爆/幼体**只读模拟值**，只有"姿态形变"允许渲染侧推导）
   ——这正是卡面强制要求的"渲染侧不得发明朝向"，他把它写成了**可扩展的契约**而非一句口号。
2. **Q5 的渲染边界**（`engine/render/**` 一行不改，客户端新增顶点格式 + 小 shader + 每类型缓存网格）
   ——把一个容易膨胀成跨层大卡的方案**约束在客户端**，与 T-A2 的做法一致。
3. **回退表 + 启动计数日志作为机器判据**——沿用 T-A2 已验证有效的手法（"选中了哪个根"进日志），
   因为"加载了 0 个"与"找错了目录"在画面上不可区分。

⚠ 一条补充要求（**写入实现卡**）：他提到 `main.cpp:734` 的 `glDisable(GL_CULL_FACE)`
是为两个立方体的镜像绕序服务的，**模型分支必须重新启用剔除**，且回退分支保持"关"。
⇒ **实现卡须成对 `glEnable/glDisable`**，否则 730 面模型会承担 2× 三角形。

### R-9（先落 B0 手写极小 `.vox` 夹具）—— **采纳，且理由很硬**

他指出：**MagicaVoxel 自带样本不是我们的资产，不得入仓**；没有夹具，引擎侧就得等美术侧。

**裁决：采纳。** 这条避免了"要么引入不可入仓的第三方样本、要么阻塞"的两难。
B0 手写夹具是本项目的既有手法（T-F1 的夹具、T-D45 的 `level_patched.txt` 同源）。

### R-10（死亡动画有模拟侧前置）—— **采纳，按他的建议分期**

PM 独立核实 `mob_sim.hpp:651` 确实当场 `store.erase(id)` ⇒ **模拟里没有"正在死亡"状态**，
**倒地动画在架构上不可实现**，不是渲染卡能绕过的。

**裁决：先做粒子版（D1），倒地版（D2）另开模拟卡**，登记 **T-D51**。

### R-13（`docs/03 §9` 加一句"美术工具不进依赖表"）—— **采纳，PM 当场落盘**

区分"代码依赖"与"美术制作工具"，避免后续把 MagicaVoxel/Goxel 误登记进依赖表。

### R-14（`mob_skin()` 借方块 id 且写错硬崩溃）—— **登记债务，留到回退分支删除时清理**

**裁决：登记 T-D52**，留到"回退分支被删除的那张卡"一并清理。
理由：现在改会动到正在工作的回退路径，属于为清理而制造风险。

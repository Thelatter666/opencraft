# 落点：assets/palettes/mossback.png —— 契约 ④
# 规则（mob_model.cpp `load_palette_png` 注释，已逐字核对）：
#   **格号 = colorIndex**。从图片左上角数，格号 = 行×16 + 列。
#   第 0 格（左上第一格）**永不使用**，第 1 格 = 索引 1。
#   （陷阱：.vox 的 RGBA 块内第 0 条 = 索引 1，整体错开一位；
#     本 PNG 刻意**不含**那一次偏移 —— 你画在哪一格，就是哪个索引。）
#
# 所以下面这张 16 行 × 16 格的图，第 1 行第 2 格 = 索引 1 = 躯干标签色。
# 行 0 容纳索引 0..15，行 1 从索引 16 开始。
#
# 字符 → sRGB（全部取自 docs/art/01-style-guide.md §2.1 的 32 色表）
#   '.'  索引无颜色 / 未使用槽 → U0 #1E1E22（§2.1 表内，饱和度 0.118）
#   'A'  W0 #423426    'B'  W1 #6E563C    'C'  W2 #8A6E4C    'D'  W3 #A8845C
#   'E'  E1 #644C3C    'F'  F0 #2E4A28    'G'  F1 #46703C    'H'  F2 #5A8C4A
#   'I'  F3 #60924E    'J'  F4 #7CA862    'K'  S5 #2E2A3A
#
# 索引占用一览（与 mossback_layers.txt 的字符表**逐条等价**）：
#   1=B W1  2=D W3  3=A W0（左前肢）  4=A W0（右前肢）  5=A W0（左后肢）
#   6=A W0（右后肢）  7=G F1  8=K S5  9=C W2  a=A W0  b=E E1
#   c=I F3  d=G F1  e=F F0  f=H F2  g=J F4
#
# alpha：全图一律 255（不透明资产，规格 §6）。
# 未使用的 17..255 槽填 U0：它们不会被任何体素采样，但填成 §2.1 表内的颜色
# 才能同时过 §8 第 5 项（图上每个 RGB 都在色板表内）与第 6 项（S ≤ 0.50）。

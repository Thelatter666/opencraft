# ============================================================================
# T-B2 · Mossback 分层字符稿（★ 创作本体，逐格手写）
# ============================================================================
#
# 这是模型的**唯一手稿**。vox_build.py 只做一件事：把本文件的字符翻译成
# .vox 的字节（体素表 + 调色板），不做任何几何运算、不做对称展开、不做填充。
# 改外观 = 改本文件，不是改脚本。
#
# ---------------------------------------------------------------------------
# 一、坐标系与朝向（与 T-B1 交付代码一致，见 docs/tasks/T-B2.md §2 契约 ①②）
# ---------------------------------------------------------------------------
#   x : 0..8   横向。x 小 = 模型的**左**侧，x 大 = **右**侧
#              （模型前方是世界 -Z，右手系里 +X 在右；已按 mob_mesh.cpp 的
#                (x, y, z)_vox -> (x, z, -y)_world 映射核对）
#   y : 0..12  前后。y 大 = 前方，y=12 是鼻端 —— **脸朝 +Y**（契约 ①）
#   z : 0..13  高度。z=0 是地面层 —— **Z 轴向上，地面 = z 0 层**（契约 ①）
#
#   每一层块的**第 1 行 = y 最大（鼻端）**，最后一行 = y=0（尾端）；
#   行内第 i 个字符 = x=i。即：把该层从正上方俯视，画面上方是生物的正面。
#   （俯视时 右=+x 上=+y 视向=-z 是右手系，与上面 x 的左右定义自洽。）
#
#   头（标签 2）在 z 7..12，躯干棕色主体在 z 5..11、苔顶到 z=13。
#   头比躯干主体高一档，苔是全身最高点 —— 这正是契约自查表防"y-up 趴地"
#   的那条判据（docs/tasks/T-B2.md §7.1：z 跨度必须 ≥2，本模型 14）。
#
# ---------------------------------------------------------------------------
# 二、字符 → colorIndex 对照（契约 ③：索引即关节标签）
# ---------------------------------------------------------------------------
#   '.'  空（该格没有体素）
#   '0'  **禁止**。索引 0 = .vox 的"无颜色"，脚本遇到 '0' 直接中止。
#
#   索引 1..8 = 关节标签（同时就是该关节的颜色）
#   '1'  1  躯干 body       W1 #6E563C
#   '2'  2  头   head       W3 #A8845C
#   '3'  3  左前肢 arm_l    W0 #423426
#   '4'  4  右前肢 arm_r    W0 #423426
#   '5'  5  左后肢 leg_l    W0 #423426
#   '6'  6  右后肢 leg_r    W0 #423426
#   '7'  7  尾   tail       F1 #46703C
#   '8'  8  备用 spare      S5 #2E2A3A   （本卡未用）
#
#   索引 9..255 = 颜色槽，**全部归躯干组**（mob_mesh.cpp: mob_joint_of_color）
#   '9'  9  躯干亮   W2 #8A6E4C
#   'a' 10  躯干暗   W0 #423426
#   'b' 11  躯干土   E1 #644C3C
#   'c' 12  苔主色   F3 #60924E
#   'd' 13  苔中间色 F1 #46703C
#   'e' 14  苔暗色   F0 #2E4A28
#   'f' 15  苔亮色   F2 #5A8C4A
#   'g' 16  苔高光   F4 #7CA862
#
#   ⇒ 一切色值取自 docs/art/01-style-guide.md §2.1 的 32 色表（木系 W0-W3、
#     土系 E1、植生 F0-F4、石系 S5），故 §3 低饱和上限 0.50 自动满足。
#     四条腿同为 W0：关节标签靠**索引**区分（3/4/5/6），不靠颜色区分 ——
#     四腿同色是有意的（一只动物四条腿本来就该同色），方位断言改由
#     vox_inspect.py 的"每索引包围盒"表作机器判据。见报告 §已知问题。
#
# ---------------------------------------------------------------------------
# 三、形体（盒体清单，供校对；稿子本身以逐层字符为准）
# ---------------------------------------------------------------------------
#   比例    网格 9(x) × 13(y) × 14(z)，1 体素 = 0.1 格
#           ⇒ 视觉 0.90 宽 × 1.30 长 × 1.40 高；碰撞盒 0.9×0.9×1.4
#           x 宽与碰撞盒对齐；y 略长于碰撞盒（前后各出 0.2），
#           与"四足兽必然比 0.9 见方长"一致的常规取舍
#
#   腿      x 1..2（左）/ 6..7（右），宽 2；后腿 y 2..4、前腿 y 6..8，长 3
#           z 0..4（高 5 = 0.5 格）—— 短粗腿，重心低
#   躯干    y 2..8，z 5..11（高 7 = 0.7 格）
#           z 6..10：y 2、y 8 → x 1..7；y 3..7 → x 0..8
#           z 5、z 11：各左右再收 1（上下倒角 ⇒ 八边形桶身）
#   颈      y=9，x 3..5，z 8..10（只有 3×1×3）—— 刻意收窄，让头读得出来
#   头      y 10..12，标签 2
#           颅 x 2..6, y 10..11, z 7..11
#           吻 x 3..5, y 12,    z 8..10
#           耳 x 2..3 与 x 5..6, y 10, z=12
#   尾      y 0..1，标签 7：y=1 x=4 z 9..11；y=1 x 3、x 5 于 z=10；y=0 x=4 z 10..11
#   苔      z 12..13，躯干组（9+）
#           z 12：y 2、y 8 → x 1..7；y 3..7 → x 0..8（比躯干顶宽 1 ⇒ 悬檐）
#           z 13：y 2、y 8 → x 2..6；y 3..7 → x 1..7（收成一条脊）
#           躯干顶 z=11 的 y=9 一行无苔 ⇒ 苔与头/颈之间留一格干净分界
#           另有苔色沿侧腹下爬：z 9..11 的 x=0 / x=8 若干格改成 'd'
#
#   轮廓读法（侧视，鼻在右）：苔丘(最高) → 颈部下凹 → 头/吻前伸。
#   z 跨度 14（≥2 ✓）；最长边 14（≤32 ✓）；体素 688（≤1000 ✓）
#
# ============================================================================

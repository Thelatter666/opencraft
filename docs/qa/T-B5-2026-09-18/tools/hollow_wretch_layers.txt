# T-B5 · Hollow Wretch 分层字符稿 v5（★ 创作本体，逐格手写）

#
# 这是模型的**唯一手稿**。vox_build.py 只做一件事：把本文件的字符翻译成
# .vox 的字节（体素表 + 调色板），不做任何几何运算、不做对称展开、不做填充、
# 不取随机数。改外观 = 改本文件，不是改脚本。
#
# 本稿是 T-B3 稿（docs/qa/T-B3-2026-09-18/tools/hollow_wretch_layers.txt）的**加密版**：
# 用户 2026-09-18 原话「这个 wretch 做的太简陋了」「体素太少，导致模型十分粗糙，
# 体素量要再翻三倍」。v4 = 169 体素 ⇒ 本稿目标 ≥450（卡面 §2.1 硬门槛），上限 1000 不变。
#
# ---------------------------------------------------------------------------
# 一、迭代（先画 -> 渲染 -> 看 -> 改；逐轮判定见报告 §5.3）
# ---------------------------------------------------------------------------
#   v4（T-B3 定稿，169 体素）：躯干只有 2 格宽 × 2 格深一根细脊，四肢 1 格宽 ——
#      远看就是"灰柱上顶一颗白颅骨"，没有体量、肘膝没有形、眼睛是 1×1 的小点。
#   v5a 只把四肢加粗到 2 格宽、画布加宽：**正面剪影从肩到手仍是一整块**
#      （手臂 x1..2 与腿在 x 上相邻）——v1 的教训换了个位置复发。
#   v5b 把手臂再外移、腿收进躯干正下方（x4..7）、中间留出 x=3/x=8 两条竖向空隙：
#      正面终于读出「臂 | 躯干+腿 | 臂」三段（出图 v5b_front.png）。
#   v5c 定稿：胸腔做出 4×4 体量、锁骨下凹进 **2 格深**（4 格索引 9）、下摆做锯齿破布边、
#      颅骨加出眉弓与下坠的下颌、眼窝放大到 **2×2**（索引 10，不挖空）、
#      骨手（11/12）之外再给双脚也上骨色（13/14 = 契约 v2 的左腿/右腿两个第二色槽位）。
#
# ---------------------------------------------------------------------------
# 二、坐标系与朝向（契约 ①，与 T-B1 交付代码一致）
# ---------------------------------------------------------------------------
#   x : 0..11  横向。x 小 = 模型的**左**侧，x 大 = **右**侧
#              （模型前方是世界 -Z，右手系里 +X 在右；映射在 mob_mesh.cpp：
#                (x, y, z)_vox -> (x, z, -y)_world）
#   y : 0..8   前后。y 大 = 前方，y=8 是眉弓/下颌的**正前方** —— **脸朝 +Y**（契约 ①）
#   z : 0..17  高度。z=0 是地面层 —— **Z 轴向上，地面 = z 0 层**（契约 ①）
#
#   每一层块的**第 1 行 = y 最大（脸那一侧）**，最后一行 = y=0（背那一侧）；
#   行内第 i 个字符 = x=i。即：把该层从正上方俯视，画面上方是生物的正面。
#
#   ★ 画布与缩放（契约 ②）：z 跨度恰 18 ⇒ 1 体素 = 1.8/18 = **0.1 格**（整数）。
#     实体落在 x1..10（**10 格 = 1.0 格宽**，与原版人形模型同宽）、y0..8、z0..17。
#     碰撞盒半宽 0.3 / 高 1.8（mob_type.cpp:107 `mob_physics("Hollow Wretch", 0.3, 1.8, 20)`）
#     ⇒ 手臂外缘 ±0.5，**探出碰撞盒 0.2**，与原版人形的臂/盒关系一致（卡面 §2.1）。
#     头顶**不加**任何附件：一加高就把整只压小（缩放口径已拍板，卡面 §6.2）。
#     ⚠ 画布 x 两端各空 1 列（x0/x11），只为让 '=== layer' 的行字符左右好读；
#       引擎取的是**占用格**的包围盒（mob_mesh.cpp centre = (lo+hi)/2），空列不影响居中。
#
# ---------------------------------------------------------------------------
# 三、字符 → colorIndex 对照（契约 v2：1..8 主标签、9..16 关节第二色、17+ 躯干组）
# ---------------------------------------------------------------------------
#   '.'  空（该格没有体素）
#   '0'  **禁止**。索引 0 = .vox 的"无颜色"，脚本遇到 '0' 直接中止。
#
#   ── 索引 1..8 = 关节主标签（同时就是该关节的第一种颜色）──
#   '1'  1  躯干 body    S1 #6E6E74   胸腔/腰腹（冷灰岩）
#   '2'  2  头   head    S4 #E2E6EC   颅骨 + 颈 + 下颌——**漂白的骨色**，全模型最亮
#   '3'  3  左臂 arm_l   S0 #4A4A50
#   '4'  4  右臂 arm_r   S0 #4A4A50
#   '5'  5  左腿 leg_l   S0 #4A4A50
#   '6'  6  右腿 leg_r   S0 #4A4A50
#   '7'  7  尾   tail    ——   本模型**未用**（人形无尾）
#   '8'  8  备用 spare   ——   本模型**未用**
#
#   ── 索引 9..16 = 关节第二色（(idx−1) mod 8 → 关节）：本卡用了**六个** ──
#   'H'  9  （关节 0 躯干二色）S5 #2E2A3A   **锁骨下的空洞**（凹 2 格深的那面墙）
#   'E' 10  （关节 1 头  二色）O0 #28282C   **眼窝**（2×2，契约判据的落点）
#   'L' 11  （关节 2 左臂二色）S3 #A6A6AC   左手（骨色，比颅骨暗一档）
#   'R' 12  （关节 3 右臂二色）S3 #A6A6AC   右手
#   'T' 13  （关节 4 左腿二色）S3 #A6A6AC   **左脚**（v5 新用：骨架一路露到脚上）
#   'U' 14  （关节 5 右腿二色）S3 #A6A6AC   **右脚**
#   （15/16 = 尾/备用的二色，本模型未用；格子在调色板里填 U0）
#   ★ 第二色**不增加关节数**：每个第二色与同关节的主色落在同一个 part 区段（同一次
#     glDrawArrays）——'E' 归头、'L'/'R' 归左右臂、'T'/'U' 归左右腿。
#   ★ 头只能用 '2' 或该关节的第二色（'E'）：任何 17+ 的躯干组色画在头上，那格会被判成
#     **躯干关节**（跟着身体转、不跟头转）——本稿一格都没有。
#   ★ 腿同理：只有 '5'/'6'（主色）与 'T'/'U'（第二色）能画在腿上；'a'/'b'/'c' 画上去
#     会让那格跟着躯干转，踢腿时留在原地——本稿腿上一格都没有。
#
#   ── 索引 17..255 = 颜色槽，**全部归躯干组**（mob_mesh.cpp: mob_joint_of_color）──
#   'a' 17  肩背/锁骨     S2 #808085   比胸腔亮一档 ⇒ 肩线读得出来
#   'b' 18  胯/腰/破布    S0 #4A4A50
#   'c' 19  背脊锈斑/驼峰 E0 #463529
#   （20..255 未使用，调色板里填 U0）
#
# ---------------------------------------------------------------------------
# 四、形体（按 z 从下往上；稿子本身以逐层字符为准）
# ---------------------------------------------------------------------------
#   z 0..7    **两条腿**：x4..5（左）/ x6..7（右），2 格宽 = v4 的两倍；与胸腔同宽、
#             正下方对齐 ⇒ 正面"臂 | 躯干+腿 | 臂"三段分明（v5a 教训的修法）。
#             髋下段 y1..3（3 格深），膝以下往前挪 1 格（y2..4）＝**膝弯**；
#             z=3 是膝节（y1..4，4 格深，比上下都厚一档 ⇒ 侧视读得出膝）；
#             z=0 是脚（y1..4），整只脚用 **'T'/'U' 骨色**（13/14）——骨架露到脚上。
#   z=8       **胯/腰**：x3..8（6 格宽，比胸腔左右各宽 1 ⇒ 腰胯有转折），y1..3
#   z=9       **破布下摆**：x3..8 一圈，前缘 x3..4 / x7..8 两片、后缘 x4..5 一片
#             （**锯齿破布边**，卡面 §2.3）——比胯还宽，压出一圈悬垂的碎布
#   z 10..13  **胸腔 4×4**（x4..7 × y1..4）＝卡面 §2.3 的"4 格宽 × 3 格深起步"；
#             z 10 整层、z 11..12 锁骨下**凹进 2 格深**：
#             y4 与 y3 的 x5..6 挖掉、y2 的 x5..6 上 'H' ⇒ 正面是一个 2 宽 × 2 高的
#             黑洞、斜视能看进胸腔里去（v4 只是 1 格深的一道缝）
#   z 12..13  **肩带**：x1..10 × y1..3，'a'（亮一档）——把两条外挂的长臂连起来
#   z=13      **下颌**（'2'）：x4..7、y6..8 —— 比颅窄 2 格、**下坠到 z=13**，
#             斜视是一颗往前下方伸出的下巴
#   z 14..17  **颅骨**：x3..8（6 格宽）、y4..7（4 格深）、z14..17；
#             z=17 多伸一格到 y=8 ⇒ **眉弓**（比眼面凸出 1 格，压在眼睛上方）
#             z 15..16 正面两角 x3..4 / x7..8 各一块 **2×2 眼窝**（索引 10）
#   z 14..15  **颈**（'2'）：x5..6、y=3 —— 只有 2×1×2，从肩带顶伸到颅后，
#             头因此是"探出去"的（低垂的头）
#   y=0       **驼峰**（'c'）：x4..7 于 z 11..13 —— 背线在肩后鼓起一格（前倾驼背）
#
#   轮廓读法（侧视，脸在右）：颅(眉弓→眼面→下颌三级台阶) → 细颈 → 肩带 → 空胸腔 →
#   破布下摆 → 细腿（膝在中间折一下）；斜视（游戏机位）能看到凹进去的胸口与两只黑眼窝。
#
#   关节数 = 6：躯干(0) 头(1) 左臂(2) 右臂(3) 左腿(4) 右腿(5)——无尾、无备用。
#   两条抗 y-up 判据：
#     ① 头 max z 17 > 躯干 max z 14（肩带顶）✓
#     ② **最锐**：接触地面的 z=0 层只有 'T'/'U'（两只脚）= 关节 4/5 ⇒ 是**站着**的 ✓
#

# ============================================================================
# T-B5 · Mossback 分层字符稿 v5（★ 创作本体，逐格手写）
# ============================================================================
#
# 这是模型的**唯一手稿**。vox_build.py 只做一件事：把本文件的字符翻译成
# .vox 的字节（体素表 + 调色板），不做任何几何运算、不做对称展开、不做填充、
# 不取随机数。改外观 = 改本文件，不是改脚本。
#
# 本稿是 T-B2b 稿（docs/qa/T-B2b-2026-09-18/tools/mossback_layers.txt）的**比例返工版**：
# 用户 2026-09-18 原话「苔背兽的身体、四条腿的比例不对，看得很怪，比例需要和 mc 里的牛对齐」。
# **只对比例**（腿高:躯干高:长:宽），物种身份（苔丘/低头吃草/色板/关节标注）全部保留。
#
# ---------------------------------------------------------------------------
# 一、比例基准：Mojang 官方 bedrock-samples `cow.geo.json`（geometry.cow.v1.8）
# ---------------------------------------------------------------------------
# 母本立方体（身体带 bind_pose_rotation [90,0,0]，折算到世界向）：
#   躯干 12 × 10 × 18 px   腿 4 × 12 × 4 px   头 8 × 8 × 6 px   角 1 × 3 × 1 px
# 1 px = 1/16 格，我们 1 体素 = 0.1 格（= 1.6 px）⇒ 折成整格（卡面 §6.4 给的取整）：
#   腿 2×7×2     躯干 8×6×11     头 5×5×4
# 本稿逐一对照：
#   腿     z 0..6（7 高）✓ 2 宽 × 2~3 深 ✓（原版 2.5 格宽，取整 2）
#   躯干   z 7..12（6 高）✓ y 1..11（11 长）✓ x 0..6（**7 宽**）
#          ★ 宽取 7 不取 8：卡面 §1.2.3 给的是"7~8"区间，取 7 的唯一原因是**头要居中**——
#            躯干 7 与头 5 同为奇数，头能左右各让 1 格完全对称（8 宽时头只能偏 0.5 格）。
#            腿粗/躯干宽 = 2/7 = 0.286，比 2/8 = 0.25 更贴原版的 4/12 = 0.333。
#   头     z 9..13（5 高）✓ x 1..5（5 宽）✓ y 13..16（4 深）✓（原版 3.8，取整 4）
#   ★ 腿高 : 躯干高 = 7 : 6 = 1.167 ≈ 原版 12 : 10 = **1.2** ✓
#     （v4 是 5 : 6 = 0.83 —— 就是用户说的"腿太短、身子太厚"）
#   ★ 四腿 x 与躯干外缘**齐平**：左腿 x0..1、右腿 x5..6，躯干 x0..6 ⇒ 外缘同列
#     （v4 腿 x1..2/6..7、体 x0..8 ⇒ 内缩 1 格 = 视觉"肚子比腿宽一圈"）
#   ★ 前后腿拉开到接近身体两端：后腿 y2..3、前腿 y9..10（躯干 y1..11）
#   ⚠ 口径澄清（卡面 §1.2）：原版**模型是高出碰撞盒的**（牛头+角到 25 px = 1.56 格 > 碰撞盒 1.4）。
#     我们对齐的**只是比例**；**缩放口径（模型 z 跨度 = 碰撞高 ÷ 0.1）不变** ⇒ z 跨度仍恰 14。
#     旁证：原版牛模型全长 26 px = 1.625 格 vs 碰撞盒 0.9 ⇒ 前后各出 ~0.36 格；
#           本稿全长 17 体素 = 1.7 格 vs 碰撞盒 0.9 ⇒ 前后各出 0.4 格。**同一量级、同一做法。**
#
# ---------------------------------------------------------------------------
# 二、高度预算（卡面 §1.2.1 写死的三条）：腿 7 + 躯干 6 + 苔 1 = 14
# ---------------------------------------------------------------------------
#   z 0..6   四腿（7 高）—— v4 是 0..4（5 高）
#   z 7..12  躯干（6 高）
#   z=13     苔盖（**1 格薄盖**）—— v4 是 z12..13 两层带悬檐的圆顶
#   ★ 苔不再抢腿的高度：v4 苔顶 z13 = 全模型最高、头反在其下；
#     本稿苔顶 z13 **恰等于**头 max z（= 13）⇒ 卡面 §4.3 的"苔顶 ≤ 头 max z"成立（取等号）。
#     这不是凑的：腿 7 + 躯干 6 已到 z=12，苔只剩 z=13 一层；头 5 高且要够到苔顶 ⇒ 只能 z 9..13。
#     卡面 §1.2.2 括号里的"最多中部 2 格"与验收判据"z 跨度仍恰 14"互相拉扯，
#     按**验收判据**执行：苔只有 z=13 一层（见报告"已知问题"）。
#
# ---------------------------------------------------------------------------
# 三、坐标系与朝向（契约 ①，与 T-B1 交付代码一致）
# ---------------------------------------------------------------------------
#   x : 0..6   横向。x 小 = 模型的**左**侧，x 大 = **右**侧
#              （模型前方是世界 -Z，右手系里 +X 在右；映射在 mob_mesh.cpp：
#                (x, y, z)_vox -> (x, z, -y)_world）
#   y : 0..16  前后。y 大 = 前方，y=16 是鼻端 —— **脸朝 +Y**（契约 ①）
#   z : 0..13  高度。z=0 是地面层 —— **Z 轴向上，地面 = z 0 层**（契约 ①）
#
#   每一层块的**第 1 行 = y 最大（脸那一侧）**，最后一行 = y=0（尾那一侧）；
#   行内第 i 个字符 = x=i。即：把该层从正上方俯视，画面上方是生物的正面。
#
#   ★ 画布与缩放（契约 ②）：z 跨度恰 14 ⇒ 1 体素 = 1.4/14 = **0.1 格**（整数）。
#     放大到世界后：0.7 宽 × 1.7 长 × 1.4 高；碰撞盒 0.9 宽 × 0.9 长 × 1.4 高
#     （mob_type.cpp:53 `mob_physics("Mossback", 0.45, 1.4, 10)`）。
#     头顶**不加**任何附件：一加高就把整只压小（缩放口径已拍板）。
#
# ---------------------------------------------------------------------------
# 四、字符 → colorIndex 对照（契约 v2：1..8 主标签、9..16 关节第二色、17+ 躯干组）
# ---------------------------------------------------------------------------
#   '.'  空（该格没有体素）
#   '0'  **禁止**。索引 0 = .vox 的"无颜色"，脚本遇到 '0' 直接中止。
#
#   ── 索引 1..8 = 关节主标签（同时就是该关节的第一种颜色）──
#   '1'  1  躯干 body    W1 #6E563C
#   '2'  2  头   head    W3 #A8845C   （比躯干亮一档 ⇒ 头一眼分得出）
#   '3'  3  左前肢 arm_l W0 #423426
#   '4'  4  右前肢 arm_r W0 #423426
#   '5'  5  左后肢 leg_l W0 #423426
#   '6'  6  右后肢 leg_r W0 #423426
#   '7'  7  尾   tail    F1 #46703C
#   '8'  8  备用 spare   本模型**未用**
#
#   ── 索引 9..16 = 关节第二色（(idx−1) mod 8 → 关节）：本模型一格不用 ──
#   四条腿同为 W0：关节标签靠**索引**区分（3/4/5/6），不靠颜色 —— 四腿同色是有意的
#   （一只动物四条腿本来就该同色），方位断言改由 vox_inspect.py 的"每索引包围盒"表作机器判据。
#
#   ── 索引 17..255 = 颜色槽，**全部归躯干组**（mob_mesh.cpp: mob_joint_of_color）──
#   '9' 17  躯干亮   W2 #8A6E4C   背线/受光面
#   'a' 18  躯干暗   W0 #423426   腹侧/边角
#   'b' 19  躯干土   E1 #644C3C   腹线泥色 + 侧腹泥点
#   'c' 20  苔主色   F3 #60924E
#   'd' 21  苔中间色 F1 #46703C
#   'e' 22  苔暗色   F0 #2E4A28
#   'f' 23  苔亮色   F2 #5A8C4A
#   'g' 24  苔高光   F4 #7CA862
#
#   ⇒ 一切色值取自 docs/art/01-style-guide.md §2.1 的 32 色表，未新增任何色，
#     §3 低饱和上限 0.50 自动满足（脚本启动时自检并打印）。
#   ⇒ **调色板 PNG 一字未动**：assets/palettes/mossback.png 与 T-B2b 交付逐字节相同，
#     vox_build.py 用同一张 palette 稿重建，md5 必须与仓库现有文件相同（报告 §4 核）。
#
# ---------------------------------------------------------------------------
# 五、形体（按 z 从下往上；稿子本身以逐层字符为准）
# ---------------------------------------------------------------------------
#   z 0..6    四腿：2 宽 × 2 深，高 7 = 0.7 格（占全高 50%；原版牛 12/26 同理）
#             后腿 y2..3 / 前腿 y9..10；z=0 是蹄，向前多出 1 格（后蹄 y2..4、前蹄 y9..11）
#             ⇒ z=0 层只有 '3''4''5''6'
#   z 7       腹线：x1..5、y2..10（比躯干四周各收 1 格 ⇒ 圆腹底；四腿外缘因此比肚子宽）
#   z 8..12   躯干桶身：x0..6 × y1..11（7×11）；z=7 收腹、z=12 平背（苔要坐在平背上，不出檐）
#             z 8 下缘用 'b'（泥色）沿两条外缘走一遭 ⇒ 泥线以下的毛色过渡
#             z 9..11 主体 '1' + 少量 'b'（侧腹泥点）、'd'（苔从侧腹爬下来的两格）
#             z 12 背线 '9'（受光）+ 背缘 'c'（苔溢出到背沿）
#   z 9..10   下颌（'2'）：x2..4、y13..16 —— 比颅窄，且**伸到比颅更前 1 格**（吻）
#   z 11..13  颅（'2'）：x1..5、y13..15
#   z 10..12  颈（'1'）：x2..4、y=12，接住躯干前脸与颅/颌后脸；颈只有 3 格宽 ⇒ 俯视时
#             躯干(7) → 颈(3) → 头(5) 有收有放，"颈"读得出来
#   z=13      颅顶：y13 只留 x1,x2,x4,x5（x=3 挖掉）⇒ 两只**耳桩**夹一道缺口；
#             y14..y15 是整排（'2'）
#   z=13      苔盖（躯干组 20..24）：y1..10；前缘 y=11 一格不铺 ⇒ 苔与颈/头之间留一格
#             干净分界（v4 的同一做法）；前缘/尾缘收到 x1..5，中段铺满 x0..6
#   y=0       尾（'7'）：x=3（z=12）、x2..4（z=11）、x=3（z=10），从臀后伸出的一小截
#
#   轮廓读法（侧视，鼻在右）：苔盖(平顶) → 颈凹 → 颅(高 5) → 吻下垂 → 前腿；
#   四腿之间是空档，且腿的外缘不缩在肚子内侧 ⇒ 不再"肚子比腿宽一圈"。
#
#   关节数 = 7：躯干(0) 头(1) 左前肢(2) 右前肢(3) 左后肢(4) 右后肢(5) 尾(6)——无备用。
#   两条抗 y-up 判据：
#     ① 头 max z 13 > 躯干组（joint 0，含苔）max z 13 取等号 ⇒ 见报告"已知问题"：
#        卡面 §1.2.1 的高度预算本身把苔放在最高层，故本稿只承诺"苔顶 ≤ 头 max z"（取等号）；
#        "头高于背"改由**躯干主体**（不含苔：索引 1/17/18/19）成立 —— 其 max z = 12 < 13 ✓
#     ② **最锐**：接触地面的 z=0 层只有 '3''4''5''6'（四条腿的蹄）⇒ 是**站着**的 ✓
#

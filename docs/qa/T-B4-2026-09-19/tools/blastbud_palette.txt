# 落点：assets/palettes/blastbud.png —— 契约 ④
# 规则（mob_model.cpp `load_palette_png` 注释，已逐字核对）：
#   **格号 = colorIndex**。从图片左上角数，格号 = 行×16 + 列。
#   第 0 格（左上第一格）**永不使用**，第 1 格 = 索引 1。
#   （陷阱：.vox 的 RGBA 块内第 0 条 = 索引 1，整体错开一位；
#     本 PNG 刻意**不含**那一次偏移 —— 你画在哪一格，就是哪个索引。）
#
# 所以下面这张 16 行 × 16 格的图，第 0 行第 1 格 = 索引 1 = 躯干主标签色。
# 行 0 容纳索引 0..15，行 1 从索引 16 开始。
#
# 字符 → sRGB（全部取自 docs/art/01-style-guide.md §2.1 的 32 色表，无表外色）
#   '.'  U0 #1E1E22  未使用槽 / 索引 0（**本稿不用作任何体素的颜色**）
#   'A'  F1 #46703C   'B'  E3 #B49E73   'C'  W0 #423426   'D'  S4 #E2E6EC
#   'E'  O0 #28282C   'F'  F0 #2E4A28   'G'  F2 #5A8C4A
#
# 索引占用一览（契约 v2，与 blastbud_layers.txt 的字符表**逐条等价**）：
#   关节主色 1..8：  1=A F1（腹体表皮）  2=B E3（芽冠）  3=C W0（左前足）
#                   4=C W0（右前足）  5=C W0（左后足）  6=C W0（右后足）
#                   7=. 未用（无尾）  8=. 未用（备用）
#   关节第二色 9..16：9=D S4（躯干二色 = 裂缝里露出的灼白内部）  10=E O0（头二色 = 五官）
#                   11..16 = 未用（其余关节的二色）
#   躯干组 17+：    17=F F0（腹底/后背/颈的暗绿）  18=G F2（肩顶受光的亮绿）
#   19..255：未使用槽填 U0
#
# 三处**借色**（色值全部在 §2.1 表内，用途登记见报告 §7 与 style-guide §9）：
#   E3（"沙的阴影带"）借作**干枯的芽冠**；S4（"雪 / 骨"）借作**裂缝里露出的灼白内部**
#   （S4 的骨色用法是 T-B3 先例）；F0/F1/F2 用作腹体表皮的暗/中/亮三级（植生系）。
#   低饱和（§3）：本稿用到的 7 个色 S ≤ 0.471（最大 F2 0.471），脚本启动时自检。
#
# alpha：全图一律 255（不透明资产，规格 §6）。
# 未使用的槽填 U0：它们不会被任何体素采样，但填成 §2.1 表内的颜色才能同时过
# §8 第 5 项（图上每个 RGB 都在色板表内）与第 6 项（S ≤ 0.50）。
#

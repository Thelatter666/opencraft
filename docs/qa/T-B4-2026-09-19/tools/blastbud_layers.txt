# ============================================================================
# T-B4 · Blastbud 分层字符稿 v2（★ 创作本体，逐格手写）
# ============================================================================
#
# 这是模型的**唯一手稿**。vox_build.py 只做一件事：把本文件的字符翻译成
# .vox 的字节（体素表 + 调色板），不做任何几何运算、不做对称展开、不做填充、
# 不取随机数。改外观 = 改本文件，不是改脚本。
#
# 意象（原创，未参考任何原版生物模型/贴图，docs/04 红线 2/5）：
#   一只**胀到快要炸开的种荚**。圆鼓鼓的腹体鼓在中间、四条短小的木质足撑在
#   下面（跑不动的体态）、顶端一颗收口的干枯芽冠；正面从芽冠的裂口起、沿着
#   表皮劈开一道**锯齿状的缝**，缝里露出**灼白的内部**（"引信已经点着了"）。
#
# ---------------------------------------------------------------------------
# 一、迭代（先画 -> 渲染 -> 看 -> 改；逐轮判定见报告 §6）
# ---------------------------------------------------------------------------
#   v1：腹体 z3..11 通体 7 格宽（正面剪影是个方柱）、裂缝正中对称地由 1 格宽到
#      3 格宽再回到 1 格、裂缝色 = O3 金。出图（renders/blastbud-v1_front_big.png）
#      暴露三个问题：
#        ① 1→3→1 的**对称加宽**在正面读成一个"十"字（规格 §4.5 明确禁止的规则形）；
#        ② 裂缝的金 O3 #D8BC78 与芽冠的 E3 #B49E73 在明度/色相上几乎同色，读不出
#           "这是内部露出来了"，倒像同一种材料；
#        ③ 腹体从 z3 到 z10 都是 7 格宽 ⇒ 正面剪影是矩形，读不出"鼓"。
#   v2（本稿定稿）三处对症改：
#        ① 裂缝改成**锯齿状**：主缝在 x4 上下贯通，z10 向右撕 1 格、z8 向左撕 1 格、
#          z6 向右撕 1 格、z4 向左撕 1 格，最鼓的 z7 开到 3 格宽 —— 不再对称、不成规则形；
#        ② 裂缝色换成 **S4 #E2E6EC（近白）**：全模型最亮的一点落在缝里，"内部亮出来"
#          读得出来，且与芽冠的沙色明显不同；
#        ③ 腹体做成真正的蛋形：z3 只 5 格宽（收在四足之间）、z4 起横向鼓到 7 格、
#          z9 起收成 5 格、z12 掐到 3 格——正面剪影是"下窄-中鼓-上收"。
#
# ---------------------------------------------------------------------------
# 二、坐标系与朝向（契约 ①，与 T-B1 交付代码一致）
# ---------------------------------------------------------------------------
#   x : 0..8   横向。x 小 = 模型的**左**侧，x 大 = **右**侧
#              （模型前方是世界 -Z，右手系里 +X 在右；映射在 mob_mesh.cpp：
#                (x, y, z)_vox -> (x, z, -y)_world）
#   y : 0..9   前后。y 大 = 前方，y=7 是五官所在的**正前方** —— **脸朝 +Y**（契约 ①）
#   z : 0..16  高度。z=0 是地面层 —— **Z 轴向上，地面 = z 0 层**（契约 ①）
#
#   每一层块的**第 1 行 = y 最大（脸那一侧）**，最后一行 = y=0（背那一侧）；
#   行内第 i 个字符 = x=i。即：把该层从正上方俯视，画面上方是生物的正面。
#
#   ★ 画布与缩放（契约 ②）：z 跨度恰 17 ⇒ 1 体素 = 1.7/17 = **0.1 格**（整数）。
#     实体落在 x1..7（**7 格 = 0.7 格宽**）、y1..8、z0..16。
#     碰撞盒半宽 0.3 / 高 1.7（mob_type.cpp:154 `mob_physics("Blastbud", 0.3, 1.7, 20)`）
#     ⇒ 身体最宽 0.7 格，比盒宽 0.6 多 0.1，**与 Mossback 的 7 格身宽同口径**
#     （T-B5 已验收：7 格身宽 / 0.6 盒），不是本卡新引入的偏差。
#     头顶**不加**任何附件：一加高就把整只压小（缩放口径已拍板，卡面 §6.2）。
#     ⚠ 画布 x 两端各空 1 列（x0/x8）、y 两端各空 1 行（y0/y9），只为让
#       '=== layer' 的行字符好数；引擎取的是**占用格**的包围盒
#       （mob_mesh.cpp centre = (lo+hi)/2），空行列不影响居中。
#
# ---------------------------------------------------------------------------
# 三、字符 → colorIndex 对照（契约 v2：1..8 主标签、9..16 关节第二色、17+ 躯干组）
# ---------------------------------------------------------------------------
#   '.'  空（该格没有体素）
#   '0'  **禁止**。索引 0 = .vox 的"无颜色"，脚本遇到 '0' 直接中止。
#
#   ── 索引 1..8 = 关节主标签（同时就是该关节的第一种颜色）──
#   '1'  1  躯干 body    F1 #46703C   腹体表皮（植生·叶的主色）
#   '2'  2  头   head    E3 #B49E73   芽冠（土系·沙的阴影带 = 干枯的冠）
#   '3'  3  左前肢       W0 #423426   左前足（木系·树皮暗纹）
#   '4'  4  右前肢       W0 #423426   右前足
#   '5'  5  左后肢       W0 #423426   左后足
#   '6'  6  右后肢       W0 #423426   右后足
#   '7'  7  尾   tail    ——   本模型**未用**（种荚无尾）
#   '8'  8  备用 spare   ——   本模型**未用**
#
#   ── 索引 9..16 = 关节第二色（(idx−1) mod 8 → 关节）：本卡用了**两个** ──
#   'W'   9  （关节 0 躯干二色）S4 #E2E6EC   **裂缝里露出的灼白内部**（"会炸"的主信号）
#   'E'  10  （关节 1 头  二色）O0 #28282C   **眼窝 ×2 / 鼻点 / 口 / 冠顶裂口内壁**
#   （11..16 = 其余关节的二色，本模型未用；格子在调色板里填 U0）
#   ★ 第二色**不增加关节数**：每个第二色与同关节的主色落在同一个 part 区段
#     （同一次 glDrawArrays）——'W' 归躯干、'E' 归头。
#   ★ 头只能用 '2' 或该关节的第二色（'E'）：任何 17+ 的躯干组色画在头上，那格会被判成
#     **躯干关节**（跟着身体转、不跟头转）——本稿一格都没有。
#   ★ 足同理：只有 '3'..'6'（主色）能画在足上；'s'/'t' 画上去会让那格跟着躯干转，
#     迈步时留在原地——本稿足上一格都没有。
#
#   ── 索引 17..255 = 颜色槽，**全部归躯干组**（mob_mesh.cpp: mob_joint_of_color）──
#   's' 17  腹底/后背/颈的暗绿（F0 叶的最暗处）
#   't' 18  肩顶受光的亮绿（F2 叶的受光处）
#   （19..255 未使用，调色板里填 U0）
#
#   ★ 明暗口径（引擎对同一朝向的面给同一个明暗系数 +y 0.72 / ±x 0.84 / +z 1.00 / -z 0.42，
#     所以**曲率只能靠色阶做**）：本体按"越靠上越亮"分三段（z3..4 暗 's'、
#     z5..8 中 '1'、z9..11 亮 't'），正面剪影两缘（每层 y 最大行之外的 x1/x7 那两格）
#     各压暗一档 → 正面读作"中间亮、两边转暗"的圆柱感。裂缝不再加暗框：
#     它两侧本就是明暗交界，加框会让正面变成竖条纹（v1 的教训）。
#
# ---------------------------------------------------------------------------
# 四、形体（按 z 从下往上；稿子本身以逐层字符为准）
# ---------------------------------------------------------------------------
#   z 0..2    **四条短足**：x1..2 / x6..7（左右）× y5..6（前）/ y2..3（后），每足 2×2×3
#             = 0.2×0.2×0.3 格。足底只占 0.3 格高（全高 1.7 的 18%）——**跑不动的体态**。
#             足比腹底（z3 只有 5 格宽）左右各外探 1 格 ⇒ 正面看是"鼓腹压在四只小短足上"。
#   z=3      **腹底**：x2..6 × y2..7（5 宽 × 6 深），整层压暗 's'，正中一点 'W'。
#   z=4      **下腹**：鼓到 x1..7 × y2..7（7 × 6，前后切角），仍整层 's'；裂缝向左撕 2 格。
#   z 5..8   **腹体主体**（4 层，最鼓）：x1..7 × y1..8（7 宽 × 8 深，四角各切 1 格）
#             ⇒ 横截面八边形。正面的裂缝在这里最开：z8 左撕、z7 开到 3 格宽、z6 右撕。
#   z=9      **上腹收口**：x1..7 × y2..7（7 × 6，前后切角），亮度升到 't'。
#   z=10     **肩**：x2..6 × y2..7（5 × 6），'t'；裂缝向右撕 2 格。
#   z=11     **颈肩**：x2..6 × y3..6（3… 实为 5 宽 × 4 深），'t'。
#   z=12     **颈**：x3..5 × y3..6（3 宽 × 4 深）——**掐到 3 格宽**并压暗（'s'），
#             裂缝从中穿过。细颈是剪影可读的关键（T-B3 的 v1 教训）。
#   z 13..16 **芽冠（头）**：x2..6 × y3..7（5 宽 × 5 深）
#               z13 = 口那一行（正面正中 3 格 'E'，两角留 '2' 做颚角）
#               z14 = 鼻那一行（正面正中 1 格 'E'）
#               z15 = 眼那一行（正面 x2..3 / x5..6 各 2 格 'E'，x4 是鼻梁）
#               z16 = 冠顶收口到 x3..5 × y4..7，**正面正中挖掉 1 格**、其后的
#                     内壁（y6,x4）画 'E' ⇒ 正面看是冠顶一道**暗色裂口**（将开未开）
#   ★ 五官全部朝 +y（正面）且都是**表面着色格**（占用表内、+y 邻居为空），
#     全部落在头关节包围盒内（判据输出见报告 §4）。头 z 上界 16 > 躯干上界 12。
#
#   轮廓读法（侧视，脸在右）：钝方的芽冠 → 掐细的颈 → 最鼓的腹（前缘 y8 比头面 y7
#   凸出 1 格，是个下坠的肚子）→ 收回的腹底 → 四只短足；正面：冠顶裂口 → 双眼 →
#   鼻 → 口 → 一道锯齿白缝一路劈到腹底（"嘴就是那道裂缝的上端"）。
#
#   关节数 = 6：躯干(0) 头(1) 左前肢(2) 右前肢(3) 左后肢(4) 右后肢(5)——无尾、无备用。
#   两条抗 y-up 判据：
#     ① 头 max z 16 > 躯干 max z 12（颈）✓
#     ② **最锐**：接触地面的 z=0 层只有 '3'..'6'（四只足）= 关节 2..5 ⇒ 是**站着**的 ✓
#
# ============================================================================

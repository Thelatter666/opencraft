# ============================================================================
# T-B3 · Hollow Wretch 分层字符稿（★ 创作本体，逐格手写）
# ============================================================================
#
# 这是模型的**唯一手稿**。vox_build.py 只做一件事：把本文件的字符翻译成
# .vox 的字节（体素表 + 调色板），不做任何几何运算、不做对称展开、不做填充、
# 不取随机数。改外观 = 改本文件，不是改脚本。
#
# 工具链与 T-B2b（docs/qa/T-B2b-2026-09-18/tools/）同构，是它的**内容替换版**：
# 索引分配表跟着本卡自己的调色板走（契约 v2，见下面第二段）。
#
# 迭代（先画 -> 渲染 -> 看 -> 改，卡面 §5.6 要求的手法；逐轮判定见报告 §4.4）：
#   v1  躯干 4 格宽、长臂紧贴它 -> 正面剪影从肩到手是一整块 0.6 宽的板，
#       "细长四肢"读不出来，整只像一块碑。
#   v2  把腰收到 2 格宽、长臂往前挪 -> 正面终于出现两道竖向空隙（臂与躯干之间），
#       但躯干 3 格深，侧视仍是一根粗柱。
#   v3  腰再收到 2 格深 -> 侧视变细，形体定了；可头还是石灰色，远看与躯干糊在一起。
#   v4  定稿：头改用 **S4 漂白骨色**（明度不设上限，规格 §3），眼窝用最暗的 O0；
#       颅骨加深到 4 格（y2..5）——一颗**白颅骨压在一具灰石枯躯上**，
#       正面/斜视里那对黑眼窝一眼就读得出来。腿顶抬到 z=8 与胯同层，接住侧向连接。
#
# ---------------------------------------------------------------------------
# 一、坐标系与朝向（契约 ①，与 T-B1 交付代码一致，见 docs/tasks/T-B3.md §2）
# ---------------------------------------------------------------------------
#   x : 0..5   横向。x 小 = 模型的**左**侧，x 大 = **右**侧
#              （模型前方是世界 -Z，右手系里 +X 在右；映射在 mob_mesh.cpp：
#                (x, y, z)_vox -> (x, z, -y)_world）
#   y : 0..5   前后。y 大 = 前方，y=5 是脸的**正前方** —— **脸朝 +Y**（契约 ①）
#   z : 0..17  高度。z=0 是地面层 —— **Z 轴向上，地面 = z 0 层**（契约 ①）
#
#   每一层块的**第 1 行 = y 最大（脸那一侧）**，最后一行 = y=0（背那一侧）；
#   行内第 i 个字符 = x=i。即：把该层从正上方俯视，画面上方是生物的正面。
#
#   ★ 画布与缩放（契约 ②）：z 跨度恰为 18 ⇒ 1 体素 = 1.8/18 = **0.1 格**（整数）。
#     x 跨度 6、y 跨度 6 ⇒ 视觉 0.6 × 0.6 × 1.8，**等于碰撞盒**（半宽 0.3、高 1.8，
#     mob_type.cpp:107 `mob_physics("Hollow Wretch", 0.3, 1.8, 20)`）。
#     头顶**不加**任何附件：一加高就把整只压小（缩放口径已拍板，卡面 §7.1）。
#
# ---------------------------------------------------------------------------
# 二、字符 → colorIndex 对照（契约 v2：1..8 主标签、9..16 关节第二色、17+ 躯干组）
# ---------------------------------------------------------------------------
#   '.'  空（该格没有体素）
#   '0'  **禁止**。索引 0 = .vox 的"无颜色"，脚本遇到 '0' 直接中止。
#
#   ── 索引 1..8 = 关节主标签（同时就是该关节的第一种颜色）──
#   '1'  1  躯干 body    S1 #6E6E74   腰腹主色（冷灰岩）
#   '2'  2  头   head    S4 #E2E6EC   颅骨——**漂白的骨色**，全模型最亮 ⇒ 头一眼分得出
#   '3'  3  左臂 arm_l   S0 #4A4A50
#   '4'  4  右臂 arm_r   S0 #4A4A50
#   '5'  5  左腿 leg_l   S0 #4A4A50
#   '6'  6  右腿 leg_r   S0 #4A4A50
#   '7'  7  尾   tail    ——   本模型**未用**（人形无尾）
#   '8'  8  备用 spare   ——   本模型**未用**
#
#   ── 索引 9..16 = 关节第二色（(idx−1) mod 8 → 关节）：本卡是 v2 的首个用户 ──
#   'H'  9  （关节 0 躯干二色）S5 #2E2A3A   **胸骨下的空洞**（凹进去那一格的面）
#   'E' 10  （关节 1 头  二色）O0 #28282C   **眼窝**（本卡契约判据的落点）
#   'L' 11  （关节 2 左臂二色）S3 #A6A6AC   左手（骨色，比颅骨暗一档）
#   'R' 12  （关节 3 右臂二色）S3 #A6A6AC   右手
#   （13..16 = 右腿/尾/备用 的二色，本模型未用；格子在调色板里填 U0）
#   ★ 第二色**不增加关节数**：'H' 归躯干 part、'E' 归头 part、'L'/'R' 归左右臂 part，
#     与同关节的主色落在同一个 part 区段（同一次 glDrawArrays）。
#   ★ 头只能用 '2' 或 'E' 两种字符：任何 17+ 的躯干组色画在头上，那格会被判成
#     **躯干关节**（跟着身体转、不跟头转）——本稿一格都没有。
#
#   ── 索引 17..255 = 颜色槽，**全部归躯干组**（mob_mesh.cpp: mob_joint_of_color）──
#   'a' 17  肩背/驼峰 亮灰  S2 #808085
#   'b' 18  胯/腰/破布      S0 #4A4A50
#   'c' 19  背脊锈斑        E0 #463529
#   （20..255 未使用，调色板里填 U0）
#
# ---------------------------------------------------------------------------
# 三、形体（设计稿）：把「空洞苦役 / 枯槁者」的意象自己拆成几何
# ---------------------------------------------------------------------------
#   意象（卡面 §3.1 四条）：细长四肢、前倾驼背、锁骨下陷的空洞感、低垂的头。
#   拆法（从上往下）：
#
#   z 15..16  颅骨 4×4（x1..4, y2..5）：**又宽又深又低**的一颗头，颜色是漂白骨色。
#             **眼窝 z=15 开在正面两角**（x=1 与 x=4 = 左右最外列、正面 y=5 那一排）
#             ——两个相隔 2 格的近黑点，上面压着一整排"眉骨"（z=16）＝ 深陷的眼。
#             ★ 眼是**第二色体素**（索引 10），**不是凹进去的格子**：剪影一格未动。
#   z 17      颅顶 2×2（x2..3, y3..4）：往前收一格（一个"斜额"），
#             侧视读出"颅 -> 顶"的台阶。**头顶到此为止**（z 跨度必须恰 18）。
#   z 13..14  颈：x2..3、y3..4（**从胸口前沿伸出**，比肩线（y0..2）还前 1 格），
#             所以头是**探出去**的，不是坐在肩上 —— 低垂的头。
#   z 12..13  肩背一整条 4×3（x1..4, y0..2）：上半身最宽最厚，且**整个偏后**；
#             驼背的"峰"从这里起。长臂就挂在这两条的末梢（x=0 / x=5）。
#   z 14      驼峰顶 2×2（x2..3, y0..1）：比肩再高 1 格、窄 1 格，头正好在它前面。
#             侧视因此是"背弓起来 -> 头探到前面"。**躯干最高点 z=14 < 头 z=17**。
#   z 8..10   **躯干只有 2 格宽 × 2 格深**（x2..3, y1..2）：一根细脊。
#             两侧 x=1 / x=4 是空的 —— 长臂因此在正面成为**带空隙的独立细柱**
#             （v1 的教训：躯干 4 格宽会把臂吞进剪影）。z=10 的背面一格是 'c' 锈斑
#             （脊椎上一道旧伤）。
#   z 11      **锁骨下的空洞**：这一层把正面那一格（y=2）整个挖掉，只剩下后排的
#             'H'（近黑）——正面看是锁骨下 2×1 的一个黑洞，侧视也真有一道缺口。
#             是**凹**，不是穿：左右没有别的列可以透过去。
#   z 6..7    裆间破布：x2..3、y2..3（z=7 满两块，z=6 只剩 x=2 的 y2..3 与 x=3 的 y3
#             = 扯破的下摆），把两腿之间的空隙在腰下收住。
#   z 0..8    **细长腿**：x=1 / x=4 各一列，1 格宽 × 2 格深，0.9 格长（占全高 50%）。
#             腿位于 **y1..2（偏后）**，而长臂在 y2..5（偏前）⇒ 侧视里腿与臂之间
#             留着空列，两条细肢**不会连成一坨**。腿顶抬到 z=8，与胯同层，
#             对 x 面接住身体（不是靠对角"贴上去"）。
#             z 0..1 是脚掌：z=0 深 3 格（y1..3，脚尖向前出 1 格）⇒ 侧视看得见脚。
#   z 5..13   **细长臂**：x=0 / x=5 各一列，1 格宽，0.9 格长（占全高 50%），垂到膝盖。
#             上臂 y2..3（z9..13）、肘 3 格深（z=8, y2..4）、前臂 y4..5（z5..7）——
#             一条**在肘部往前折**的垂臂，手落在身前。z=5 那格是 'L'/'R'（骨色的手）。
#             臂的支点：与肩条（z12..13）在 y=2 那一列相贴，其余全悬空 ——
#             正是"挂着"的读法。
#
#   关节数 = 6：躯干(0) 头(1) 左臂(2) 右臂(3) 左腿(4) 右腿(5)——无尾、无备用。
#   两条抗 y-up 判据：
#     ① 头 z 高于躯干：头 max z 17 > 躯干 max z 14（驼峰顶）✓
#     ② **最锐**：接触地面的 z=0 层只有 '5'/'6'（两条腿的脚掌）⇒ 是**站着**的 ✓
#

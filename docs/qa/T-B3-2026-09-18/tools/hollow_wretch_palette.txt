# 落点：assets/palettes/hollow_wretch.png —— 契约 ④
# 规则（mob_model.cpp `load_palette_png` 注释，已逐字核对）：
#   **格号 = colorIndex**。从图片左上角数，格号 = 行×16 + 列。
#   第 0 格（左上第一格）**永不使用**，第 1 格 = 索引 1。
#   （陷阱：.vox 的 RGBA 块内第 0 条 = 索引 1，整体错开一位；
#     本 PNG 刻意**不含**那一次偏移 —— 你画在哪一格，就是哪个索引。）
#
# 所以下面这张 16 行 × 16 格的图，第 0 行第 1 格 = 索引 1 = 躯干主标签色。
# 行 0 容纳索引 0..15，行 1 从索引 16 开始。
#
# 字符 → sRGB（全部取自 docs/art/01-style-guide.md §2.1 的 32 色表）
#   '.'  U0 #1E1E22  未使用槽 / 索引 0（**本稿不用作任何体素的颜色**）
#   'A'  S0 #4A4A50   'B'  S1 #6E6E74   'C'  S2 #808085   'D'  S3 #A6A6AC
#   'P'  S4 #E2E6EC   'F'  S5 #2E2A3A   'G'  O0 #28282C   'M'  E0 #463529
#
# 索引占用一览（契约 v2，与 hollow_wretch_layers.txt 的字符表**逐条等价**）：
#   关节主色 1..8：  1=B S1  2=P S4（漂白的颅骨）  3=A S0（左臂）  4=A S0（右臂）
#                   5=A S0（左腿）  6=A S0（右腿）  7=. 未用  8=. 未用
#   关节第二色 9..16：9=F S5（躯干二色 = 胸前的空洞）  10=G O0（头二色 = 眼窝）
#                   11=D S3（左臂二色 = 左手）  12=D S3（右臂二色 = 右手）
#                   13..16 = 未用（右腿/尾/备用 的二色）
#   躯干组 17+：    17=C S2（肩背/驼峰）  18=A S0（胯/腰/破布）  19=M E0（背脊锈斑）
#   20..255：未使用槽填 U0
#
# ★ 与 T-B2b 的 mossback 调色板差别（写下来备核）：
#   · 躯干组只用 17..19 三格（mossback 用了 17..24 八格）；
#   · 9..16 这一整段**被真正用起来了**（9/10/11/12 四格），这是契约 v2 的首个实例；
#   · 色相从 mossback 的木/植生系换成**冷灰石系 S0/S1/S2/S5 + 漂白骨色 S4 + 眼窝 O0 +
#     一点土 E0**。S4 在 §2.1 的用途栏写的是"雪"，本卡借它做**漂白的颅骨**：
#     规格 §3 明说"明度不设上限：雪 #E2E6EC 允许接近白"，而 S4 本身归**石系**，
#     骨/石同族 —— 用法在报告 §5 里写明，未新增任何表外色。
#
# alpha：全图一律 255（不透明资产，规格 §6）。
# 未使用的槽填 U0：它们不会被任何体素采样，但填成 §2.1 表内的颜色
# 才能同时过 §8 第 5 项（图上每个 RGB 都在色板表内）与第 6 项（S ≤ 0.50）。
#
# 饱和度自检（§3，逐色 S=(max−min)/max）：B 0.052 / C 0.038 / D 0.035 /
# A 0.075 / F 0.276 / G 0.091 / M 0.414 / P 0.042 / U0 0.118 —— 最大 **0.414** ≤ 0.50 ✓

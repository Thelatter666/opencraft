## 0. 它解决什么问题

T-B1 的成败线是「**没有 `assets/mobs/*.vox` 时，画面与今天逐像素相同**」，
并且装置**必须先自证能分辨两棵树**（`docs/05 §3.1` 第 12 条同一思路）。
难点：生物是**活的**——它会走、会转头，两次运行本来就不一样，
于是"逐像素相同"根本无从判定。

## 1. 装置四个门（rev2；每一道都是当天撞出来的）

| 门 | 做法 | 不用它会怎样 |
|---|---|---|
| ⓪ **流式平台**（rev2 新增） | 暂停**之前**，等 `fps` 行里 `chunks K / stream-meshed M` **连续三行读数相同**才动手 | 暂停会把流式进度一起冻住。rev1 没这道门：ESC 落在不同 chunk 数上，"两次逐字节各自静止"的世界其实**不是同一个世界**（实测假差异 **566,858 / 957,440** 像素，差点误判成败线失败） |
| ① **暂停确认** | HID 注入 ESC 后，轮询日志最后一条 `EVIDENCE paused=`，必须是 `1` | 注入失败时画面明亮且在动，**看起来就像渲染回归**（实测"92 万像素不同"全是这个假象） |
| ② **画面静止** | 连拍两张（间隔 0.4 s）**md5 必须相同**，不同则重试 | 暂停后**区块流式加载仍在继续**（chunk 计数会继续涨一段时间），画面并未马上定型 |
| ③ **同状态** | 两个夹具补丁（下方 02/03）钉死"每次运行都不同的东西" | 同二进制两次运行也会差 452–11,607 像素（别人家的方块） |

## 2. 三个补丁（**只用于取证树，绝不入产品代码**）

| 补丁 | 位置 | 作用 | 不打会怎样（实测） |
|---|---|---|---|
| `01-harness-client-hooks.patch` | `game/client/src/main.cpp` | F6/F7/F8 在**暂停态**召唤三种生物各一只（放在 `!paused` 判定之外）；并在暂停状态翻转时打 `EVIDENCE paused=` | 拿不到"暂停已生效"的机器判据 |
| `02-harness-fixed-spawn-yaw.patch` | `sim/mob_sim.hpp:601` | 把生成时的随机朝向 `random_range(rng, 0, 2π)` 改成**固定 0.7** | 两足立方体的**头块**朝向随机 ⇒ 同二进制两次运行差 **11,607** 像素 |
| `03-harness-no-natural-spawn.patch` | `sim/mob_spawn.hpp` | 自然刷怪上限 `hostile/passive_cap_per_window = 0` | 自然刷出的远距离生物时有时无 ⇒ 差 **452** 像素 |

三处都只在**取证用的临时检出**里打，产品分支零改动；
这与 T-M2 把临时召唤钩子存档、事后 `grep -c EVIDENCE = 0` 证明已还原是同一套纪律。

## 3. 装置自证（2026-09-18，基线树实测）

```
① 同二进制 + 同模式 两次运行     ：0 / 957,440 像素差        ← 噪声地板 = 0
② 单次运行内两连拍               ：0 / 957,440 像素差        ← 画面静止
③ 灵敏度（有/无召唤生物）        ：105,469 / 957,440 像素差  ← 11.0%，装置确实看得见生物
   差异像素主色 = 暗化后的泥土棕 + 草绿（= 苔背兽两足立方体的体色）
```

⇒ **装置能分辨"少一只生物"，且相同输入下输出逐字节一致。**
（自证图与日志见 `selfcheck/`；两份日志里 `EVIDENCE summon`、`paused=1`、`spawned at` 计数可查。）

## 5. 独立夹具（`make_vox.py` + `fixtures/`）

**不依赖开发者的 B0 夹具**：自写生成器产出 1 个合法模型 + 8 种损坏变体，
用于独立验证解析器与回退表（`research/12 §6.5`）。独立是重点——同一份错误假设
（尤其"`RGBA` 块第 0 条 = 索引 1"这条整体错一位的坑）会同时出现在解析器和它自己的测试数据里。

模型：`SIZE (7,5,3)`、**8 体素**（沿 +X 的 5 长横排 + 其 -X 端 3 高立柱，**故意不对称**），
调色板 3 条：索引 1 = 红（身）、2 = 绿（头）、3 = 蓝（诱饵，模型不用）。
调色板 PNG `pm_palette_magenta_cyan.png` 把 1/2 格改成**品红/青**
⇒ **上屏若从红/绿变品红/青，说明 PNG 通道生效**（内置 `RGBA` 兜底则是红/绿）。
⚠ **`.vox` 的竖轴是 Z**（MagicaVoxel 约定）。`pm_good.vox` 的立柱沿 +Y：它能被正确
**解析**（校验只查"在 SIZE 内"，8 体素/68 三角形全对），但渲染成趴地平板——
适合做解析/几何断言，**不适合做视觉比对**。视觉用 `pm_good_zup.vox`（立柱沿 +Z，`SIZE z=4`）。
本目录的这条弯路已固化进 `make_vox.py` 头注与 §5 表，供 B2/B3/B4 的夹具作者避坑。

| 夹具 | 植入的毛病 | 期望行为（回退表对应行） |
|---|---|---|
| `pm_good.vox` | —（立柱沿 +Y，见上） | **解析成功**（8 体素/68 三角形）；仅用于解析/几何断言 |
| `pm_good_zup.vox` | —（立柱沿 +Z，正确约定） | **加载成功**；`mobs: N/3` 计入；画面出现红身绿头的体素模型 |
| `pm_bad_signature.vox` | 头 `VOX2` | 回退两立方体 + **1 条 WARN** |
| `pm_truncated.vox` | 尾部截断 | 回退 + 1 条 WARN（含原因） |
| `pm_chunk_overrun.vox` | chunk 声明长度越过文件尾 | 回退 + 1 条 WARN（**不得**越界读） |
| `pm_count_lies.vox` | `numVoxels=100` 但只有 8 组坐标 | 回退 + 1 条 WARN |
| `pm_out_of_bounds.vox` | 体素 x == SIZE.x | 回退 + 1 条 WARN（**不得默默钳制**） |
| `pm_no_size.vox` | 缺 `SIZE` 块 | 回退 + 1 条 WARN |
| `pm_huge_size.vox` | `SIZE.x = 4096`（超上限） | 回退 + 1 条 WARN |
| `pm_zero_voxels.vox` | 结构合法但 0 体素 | 回退 + 1 条 WARN |

用法：把某一个文件复制进取证树的 `assets/mobs/` 并**改名为某个 `<mob_id>.vox`**（如 `mossback.vox`），
再用 `run_scene.sh ... mossback` 取图。⚠ `fixtures/` 只存在于本目录，**绝不能进 `assets/`**
（成败线要求"无模型文件"那一侧必须真的没有模型文件）。

# 02 · 世界生成与内容组织规格

数值来源：`research/02-mc-worldgen-content.md`（JE 1.18+ 基准）。原则：**生成结构可对齐（参数、层次、分布逻辑），生成产物表达原创**（噪声组合、群系名、结构外观自定）；同种子同版本确定性可复现是硬要求。

## 1. 世界骨架

- 主世界：Y ∈ [−64, 319]，区块 16×384×16（24 个 section）；海平面 Y=63；世界边界 ±29,999,984。
- 种子：64 位整数；同种子+同版本 → 世界确定性一致（黄金文件快照测试覆盖）。PRNG 采用公开算法（xoroshiro128** 系列）。
- 下界（M5+）：Y ∈ [0, 127]，底/顶岩层封闭，主世界:下界坐标比 1:8。末地（M5+）：主岛+环状外岛+折跃门等价物。
- 区块加载：以玩家为中心的方形视距（默认 12 区块渲染 / 10 区块 tick），spawn 区块常驻。

## 2. 地形生成管线（分层、可缓存、可测试）

1. **连续气候场**：温度/湿度/大陆性/侵蚀性/怪异性 PV 六参数噪声（fBm+域扭曲），群系=参数空间查表+最近匹配，保证群系间平滑过渡、同群系连片。
2. **基础地形**：3D 密度函数（OpenSimplex2 为主）+ 高度偏置 → 实体/空气判定；地表规则层（草/土/石的分层、水下/山地变体）。
3. **洞穴**：三类——"奶酪洞"（大空腔）、"意面洞"（细长管道）、"面条洞"（蠕虫隧道）等价物；入口可达地表。
4. **矿石分布**：矿种按 Y 层峰值分布（对齐设计逻辑）：煤（Y45 峰值、全层可用）→ 铜（Y43，大团簇）→ 铁（Y14 主峰+高山副峰）→ 金（Y−18）→ 红石/钻石（Y−59）→ 青金石（Y−2）。具体数值在实现时以 `research/02` 为准做分布曲线。
5. **结构**：spacing/separation/salt 网格放置（村庄 34/8、府邸 80/20、神殿 32/5 等），要塞类用同心环（128 个、8 环）+ 探索地图定位等价物。首发结构：村庄、废弃矿井、沙漠神殿、要塞、沉船（5 种）。
6. **装饰**：树木（按群系多形态）、花草、湖/泉水；树可跨区块——用"邻区就绪门槛"的状态机解决（见 `03-architecture.md` §3）。

## 3. 生物群系（首发 ~25，最终 ~60）

对齐**生态位分布逻辑**（温度×湿度矩阵），名称全原创：
- 温带：草原、森林、桦林等价物、沼泽、沙滩、海洋（温暖/温和/寒冷/冻洋）
- 寒带：针叶林、雪原、冰刺、山地（风袭丘陵/山脊等价物）
- 干热：沙漠、恶地、热带草原
- 洞穴生物群系（M4+）：繁茂洞穴、溶洞等价物
- 群系决定：地表方块、树木形态、被动生物表、天空色/雾色、结构表

## 4. 时间/天气/重生

- 昼夜 24000 tick；月光随月相（8 相）影响天空亮度；怪物生成主要受方块光 0 限制（天光夜间≠0 但按光照公式衰减）。
- 天气：雨/雷暴状态机（`research/02` §5 数值）；雷暴可点燃火、骷髅马陷阱等价物后置。
- 床等价物：夜间跳到清晨+设重生点；下界等价物重生锚（M5+，爆炸规则对齐）。

## 5. 存储与存档组织

- **不复制 Anvil 格式**，但采纳其设计动机：区域文件聚合（32×32 区块/文件）+ 8KiB 头（位置表+时间戳）+ 4KiB 扇区 + 每区块独立压缩（zstd，块头存未压缩长度）——自定格式细节与魔数。
- 区块内容：调色板压缩的方块数组、区块实体（tile entity）、实体列表、光照缓存（可选重算）。
- 目录：`level/`（主世界）、`level_nether/`、`level_end/`、`entities/`、`players/`、`level.dat`（种子、时间、gamerule、难度、出生点）。
- 写入：脏区块定时批量异步回写 + 临时文件原子替换，防崩溃损坏。

## 6. 内容组织

- 难度：4 档 + 区域难度（0.75–6.75，由月相/游戏天数/区块驻留时间驱动），影响敌对伤害、饥饿伤害、刷怪装备概率。
- 游戏规则：注册表式 gamerule，`level.dat` 持久化。
- 进度树（M5+）：5 棵树（主线/冒险/技巧/下界/末地等价物）约 120 节点规模；JSON 数据驱动，模组可加节点。
- 统计：9 大类（ mined/crafted/broken/killed/killed_by/used/picked_up/dropped/custom ），距离以格、时间以 tick 计。

## 7. 验收方式

- 种子确定性测试：固定种子 × N 组关键坐标，区块快照哈希进黄金文件。
- 分布测试：批量统计矿石出现频率曲线、群系面积占比、结构间距，与规格曲线比对。
- 可玩性测试：出生点 5 分钟内可见地表资源闭环（树+石+地表矿）。
